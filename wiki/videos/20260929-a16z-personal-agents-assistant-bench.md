## 概要

- **横评规模**：⚠️ 全品类 **122 个** agent 在跟踪，**他个人测了 26 个**；收费结构是 **65 个收费（35 全付费 + 30 freemium），只有 13 个完全免费**——⚠️ **而两个占主导的（Muse、Instinct）都免费**。
- ⚠️ **本期最该被记住的一条判断**："**普通人根本不在乎效率提高 10%**"——所以赢家不是 time saver 而是 **cost saver**，而且必须是**隐形的**。
- ⚠️ **护城河之争**：**人格不是护城河**（一句话就能改配置），**proactivity（主动性）才是**——但它有一条一旦越过就全盘失信的线。
- **界面**：iMessage / 独立 app / 小组件 / 硬件并存，⚠️ **可能按世代、甚至按性别分化**；语音被两人同时列为当周的"第二个魔法时刻"。
- ⚠️ **一条对整波产品的祛魅**："**现在的消费级 agent 基本就是 Open Claw 的复刻，只是预配置好了。**"
- **商业侧**：成本约 ⚠️ **每用户每天 20 美元**；Amazon 封锁与 Shopify 开放被拆成**广告模式与去中介化**两个动机。

## 核心观点

### Assistant Bench：一个消费向而不是技术向的基准

- **它测什么**（[00:03:02]–[00:04:03]）：对所有助理**发同一条提示词**（"帮我订一张去芝加哥的机票"、"在我位置五个街区内找一家素食餐厅"），⚠️ **比的是一次性提示下的实际结果**——**它真的做成了吗？它会不会追问？在 16 个维度上表现如何？回复有多快？**
- ⚠️ **他对"benchmark"这个词的自我限定（本库认为这条该照录）**（[00:04:03]）：**"我们用了 benchmark 这个词，但把它想成一个面向消费者的基准，不一定是幕后的技术基准——如果我要订一张机票，我到底该用哪个？"**
- **起因与反响**（[00:04:03]–[00:05:03]）：他做这个最初只是**自己做市场调研**；上线 **16 天**，网站**超过 10 万访客**，"**基本每一个创始人都来联系过**"。
- **品类划分**（[00:05:03]–[00:06:03]）：⚠️ **两大类**——**B2C 通用型**（Instinct、Muse，以及 Caddie、Ollie、Season 等长尾，他说光通用这一类就有 **64 个**）和 **B2B 工作流型**（更像行政助理）；通用类下面还能再切出**垂直**（旅行、邮件各有专门的）。⚠️ **全品类合计 122 个。**
- **集中度**（[00:06:03]）：⚠️ **"现在绝大多数人都在做通用横向的，就是什么都想做。"**

### ⚠️ 用例排序，以及它的样本偏差（本页最该带着警告读的一段）

（[00:07:05]–[00:09:07]）他的数据来自 **7、8 个群聊、合计 1200 多人**。

| 名次 | 用例 | 他的说明 |
|---|---|---|
| 1 | **日常杂务** | 清收件箱、替你填表——"**那些真正烦人的事**" |
| 2 | **agent 编排** | 怎么找到最高效的 agent、怎么让你的 agent 互相对话 |
| 3 | **开发** | 从短信里用 coding agent；设计师用短信改设计文件的小迭代 |
| 4 | **旅行** | ⚠️ **"病毒传播上它是第一，但人们不是每天旅行，所以它更像一个噱头、一次注意力抓取。"** |
| （另记） | **金融** | ⚠️ 他说这是**最有意思也最不实际的一类**——"**如果一个 agent 真能帮你赚十亿，对冲基金早就在干了**"；但有意思的是"**你把一个强力工具放进人手里，他第一个念头是：你要怎么帮我赚一百万？**" |

⚠️ **他自己主动标注了样本偏差**（[00:08:07]）：**"这些群聊都是科技 Twitter 的人，不一定代表更大的世界。"** ⚠️ **本页把这条前置**：这份排序是**早期采用者的排序**，不是消费者的排序；"agent 编排"和"开发"排到第 2、3 位几乎必然是这个偏差的产物。

### ⚠️ "省钱胜过省时"：本期最可被后续检验的一条论题

- **起点是一条被转述的反论**（[00:09:07]）：Anish 引 **Ben Thompson 在 TBPN 上的说法**——⚠️ **"大多数消费者在生活里要的不是生产力，他们要的是花掉时间，不是省下时间。"** 他说自己同意。
- ⚠️ **Pawlan 把它推成了产品结论**（[00:10:07]）：**"普通人根本不在乎效率提高 10%。"** 他的类比很具体：**"你雇一个助理，是为了让他隐形。我带过的最好的员工就是那种自己把活干完、然后告诉你'我做了这些'的人——你不是因为喜欢管人才雇人的。"**
- ⚠️ **于是他给出本期的核心预测**（[00:10:07]）：**"我们会看到一次爆发，但它不是 cost maker，是 cost saver。"**
- **他举的三个例子（⚠️ 均为口述、未核实）**：
  - 有人让 agent **翻过去一年的收据去申报 HSA 报销**；
  - 他自己的用法：**每次订机票后，若票价下跌就让助理去找航司要旅行积分**；
  - ⚠️ **他最喜欢的一个**（[00:11:07]）：**有朋友把 Grok bot 接到自家洒水系统并连上天气系统，洒水随天气走，水费降了 50%。**
- ⚠️ **Anish 给了这条一个更锋利的包装**（[00:11:07]）：**"美国消费者不想听省钱，想听花钱和白来的钱。所以这里的钩子会让人觉得是白来的钱"**——补 HSA 报销是白来的钱，拿回机票差价也是白来的钱。
- ⚠️ **本页标注一处两人都没展开的张力**：**"省钱胜过省时"与"消费者要花掉时间而不是省下时间"其实并不是同一条**。Ben Thompson 的论点是**消费者不追求效率**；Pawlan 的解法是**那就别卖效率，卖回收到的现金**。**这两者相容**，但它同时意味着 ⚠️ **这一波消费 agent 的价值主张本质上是金融性的，而不是能力性的**——而金融性的价值主张**有上限**（你能被追回的钱是有限的），**两人都没有讨论这个上限**。

### proactivity 是护城河，人格不是

- **先否掉人格**（[00:24:16]）：Pawlan 承认人格差异真实存在（他举 **Poke** 的例子——"它太'拽'了，我有朋友拒绝给它任何个人信息，因为跟它对话让人不舒服"），⚠️ **但"人格不是一条可防御的护城河，因为它太容易配置了"**——"你发条短信说你希望它怎么回话，它就存进记忆或者 soul file，就好了"。
- ⚠️ **Anish 的 steel man：把"人格"下推成能力**（[00:25:17]）：他提出**不是人格而是"宪法（constitution）"**，并给了一个具体维度——**presumptuousness（擅自做主的程度）**：**"有些活你希望 agent 非常擅自做主，你宁愿它 10% 的时候出错，只要它经常真把事办了；而另一些（比如金融 agent）你希望它极度谨慎。"** ⚠️ **他的落点是本页最有用的一条抽象：这些现在被叫做"人格"的东西，会下沉成能力，变成"它在歧义处怎么打破平局"——而那里有防御性。**
- ⚠️ **Pawlan 的回答直接给了本期标题级的一句**（[00:25:17]）：**"proactivity 有巨大的防御性。我认为这正是把赢家和大部队分开的东西——那个最能主动、能当一个隐形助理、不用你开口就开始替你做事的 agent。"**
- ⚠️ **然后他画了那条线（本页认为这是全期最可操作的一段）**（[00:26:17]）：

| | 可以主动做 | 必须先要授权 |
|---|---|---|
| 判据 | ⚠️ **你这边不需要任何动作** | ⚠️ **需要你这边改变行动、且直接影响你** |
| 例子 | "我替你起草了这封邮件"、"我替你要到了机票积分" | **发现你的保险收费过高，于是替你换一家保险** |
| 性质 | 省你钱、省你时间 | 一次代你做出的实质决定 |

- ⚠️ **而他给的后果是不对称的**（[00:26:17]）：**"这会是一条非常细的线，因为只要你越过一次，你就立刻失去用户的全部信任。"**
- ⚠️ **Anish 的反向意见本页也记**（[00:27:17]）：**"很多魔力恰恰来自擅自做主。如果你没在 X 上看到人们发'agent 干了这个、agent 干了那个'，那反而说明这些 agent 在这个方向上推得不够狠。"** 他们拿一个段子收尾：⚠️ **"我们内部开玩笑说，离某个 agent 发消息说'我注意到你对她没那么上心，所以我替你把她甩了'只剩几天了。"**
- ⚠️ **一处本库要标注的存疑事实**（[00:27:17]）：Anish 提到网上流传"**Instinct 替某人值机时把中间名幻觉成了别的东西，导致他登不上飞机**"，但他**当场怀疑真实性**——"我不确定这是不是在 shitposting"。**本库照录这条怀疑，不照录那个事件。**

### 界面之争：iMessage、独立 app、语音、硬件

- **两种主要表面**（[00:12:08]–[00:14:09]）：iMessage 与独立应用；他提到还见过第三种（某个 Signal 方向的创业公司做 **iPhone 小组件**）。
- ⚠️ **Anish 的分化假设**（[00:13:09]）：**可能按世代分化**（Z 世代更愿意直接发短信，千禧与 X 世代更愿意用 app 界面），**可能还按性别分化**（他拿自己和太太对比：她偏视觉界面、做梦想板和年度目标，他偏功能——"我就想知道怎么从 X 到 Y"）。⚠️ **他自己限定了这是一个 generalization。**
- ⚠️ **他对 iMessage 的说法值得记**（[00:13:09]）：**"iMessage 这个空间更珍贵……它在我手机上处在一个特权位置，而 app 网格上的图标没有。"** 但他立刻给了失效条件：**"当然，如果每隔一个会话就是一个 agent，这件事就会变。"**
- **语音**（[00:17:09]–[00:19:10]）：⚠️ Pawlan 称 ChatGPT 语音接入连接器是他 **"这整个 AI 助理浪潮里的第二个魔法时刻"**——**骑车上班的 30 分钟里把邮件分类打标签、回了几封、发出日历邀请，到工位时收件箱清零**。Anish 补了技术面：**全双工、能看到你所有会话**，所以你可以问"我开过的那三个项目现在到哪了"。
- ⚠️ **Pawlan 由此给了一条界面原则**（[00:18:09]）：**"助理最有用的时候，是你最被占住的时候——不是你坐在沙发上花时间用它，而是你在园艺、在做饭、手上腾不开、没法跟界面互动的时候。"**
- **硬件**（[00:14:09]–[00:17:09]）：
  - ⚠️ **Anish 的警告**：**"每一个在做硬件的人都觉得自己那块硬件是终极答案——吊坠是终极、表带是终极。我不认为那是对的。"** 他的判断是**像首饰一样因人而异**，但"**有一个随身的、环境式的东西去捕捉一天里全部的上下文、请求、承诺，这件事是有价值的**"，并提醒**社会还得一起把隐私预期摸出来**（"华盛顿有些餐厅会收走你的手机，也许以后连吊坠也收"）。
  - ⚠️ **Pawlan 的"hot take"**（[00:15:09]–[00:16:09]）：**Muse charm 与其说是要赢硬件，不如说是 Meta 在真实世界里采数据**——"它有摄像头和多个麦克风……我不觉得它会被大规模采用，会被 Twitter 泡泡里的人用起来，然后**给 Meta 喂进荒谬数量的数据，去喂 Zuckerberg 未来那个把真实世界映射出来的 metaverse**"。
  - **Anish 的反问与他的回答**：**"他们不是已经从眼镜拿到这些了吗？"**——⚠️ **"吊坠是环境式的 24/7 陪伴，眼镜更偏行动导向"**（眼镜不会一直开着）。
  - ⚠️ **Anish 的沉睡黑马判断**（[00:16:09]–[00:17:09]）：**纯音频眼镜可能是 sleeper hit**——理由是社交尴尬：**"有一部分人喜欢脸上戴摄像头，但另一些人意识到它会让别人不舒服，他们想要连接但不要摄像头带来的社交别扭。"**

### 多人场景：三种做法，以及"把麦克风交给 agent"为什么别扭

- **Anish 的观察先于方案**（[00:20:11]）：⚠️ **"按我自己做 agent 的经验，把 agent 加进群聊会让人觉得侵入，或者说它削弱了社交资本。"**
- **Pawlan 归纳的三种做法**（[00:20:11]–[00:21:12]）：
  1. **直接加进群聊**（传统做法）；
  2. ⚠️ **agent 网络**（Instinct 的做法）：**你邀请对方的 agent，两个 agent 在幕后替各自主人对话，然后分别向你汇报**；
  3. ⚠️ **沉默的听众**（他说最有意思的一种，产品名 **Doc**，来自 Shane Mac / XMTP，⚠️ 也是 a16z 被投）：**agent 加进群聊但全程不说话，只听、只记笔记；有行动项时单独私信相关的人**；想看讨论就去文档里看。⚠️ **他的总结**：**"又回到隐形 agent——你不知道它在，它在做你想要的那些杂务，有行动项时也不打扰大多数人。"**
- ⚠️ **Anish 给了一条解释为什么群聊这么难**（[00:22:14]）：**"消息这件事就像是有人拿着麦克风，而把麦克风交给 agent 让人不舒服；而换成 Discord 或者传统网络论坛，agent 可以发一个帖子，你可以选择接或不接，Reddit 那种——不知道为什么，那就没那么侵入。"**
- ⚠️ **Anish 引的一条能力判断（本库值得单记）**（[00:21:12]）：他引 **Near** 的说法——**模型在可验证域（比如写代码）上的进展当然是指数的，但在纯散文质量、甚至"临床关怀式的口吻（bedside manner）"上，可能已经平台期、甚至在变差**。⚠️ **他由此得出一个产品结论：以今天的模型，agent 很难真正增进一个群的社交连接；而"非常功利"的 agent 可以。** 他举自己的实验：**他是收藏者，把 agent 加进和藏友的聊天里去编目各自的收藏和口味**——"还没完全做成，但至少感觉它是在给这个群加东西，而不是一个低情商机器人在我们不想要的时候叨叨"。
- **一处设计观察**（[00:23:14]）：⚠️ **"我们是不是把这些 agent 人性化得有点过头了。"** 对照是：有些公司把形象做成 **AI 生成的人**（让人不舒服），而另一些做成**可爱的卡通形象**，后者反而被喜欢。

### assistant 还是 agent：一个定义，以及一条社会学猜测

- ⚠️ **Anish 的定义**（[00:32:21]）：**"assistant 是比 agent 更低的一种形态。assistant 按定义只能做你让它做的事；而 agent 有 agency，它可以就这么让好事在世界上发生。"** 他把这接到企业侧：**agent 从实习生起步，随着做事和智能提升被"提拔"去做更高阶的工作**——⚠️ **"那么在消费者的生活里，被提拔去做更专门、更微妙的工作又意味着什么？"**
- ⚠️ **Pawlan 的反向担心**（[00:33:22]）：**"'agent'这个词会不会让我们对 AI 人格化得不够？'assistant'会不会又加了太多人味，让社会不舒服？"**
- ⚠️ **Anish 给了一条本库此前没有的正面设想**（[00:33:22]–[00:34:23]）：**agent 可以提供一层"社交间接性（social indirection）"**——"有些话我当面对你说会尴尬，或者一个群里有不舒服的动态；一个设计得很仔细的 agent 可以帮忙给反馈、或者把冲突组织成一种不带情绪的形式，**因为你知道它不是人**"。⚠️ **他自己立刻加了限定**："我不是在提倡一个更被动攻击的社交系统。"

### ⚠️ "这一波基本就是 Open Claw 的复刻"

（[00:28:17]–[00:29:19]）⚠️ **本页认为这是整期最有祛魅价值的一段，而且它出自一个测了 26 个产品的人。**

- **他的判断**：**"现在我老实说，消费级 agent 基本就是 Open Claw 的复刻，只是预配置好了。在个人助理这个空间里，我没看到什么是用 Open Claw 或者 Hermes 做不到的。"**
- ⚠️ **他说真正的差别在哪儿**：**"只不过你不用自己配置，不会每 7 小时弹一次报错，而且它非常好用，界面很简单。"**
- **他对走向的两条判断**：**继续走向生产力**；**继续走向超垂直专业化**——他举的例子是 ⚠️ **"一个只服务三岁以下孩子的单亲妈妈的助理，它知道这位妈妈的日常怎么运转、知道儿童发育，让人觉得这个助理在读她的心"**，而这种东西**可以成为通用 agent 的一个插件**。
- ⚠️ **本页的交叉标注**：这条与本库 [OpenClaw 那期](20260212-lex-openclaw-steinberger.md) 构成完整的一条线——**开源原语先出现、被大量个人配置使用，半年后被产品化成消费品，而产品化增加的价值被这位横评者判定为"配置与可靠性"，不是能力。** 它也与 [Jason 在 All-In 09-26 的观察](20260926-all-in-anthropic-ipo-open-source-flip.md)（Meta 表示 Muse 的设计大量借鉴 OpenClaw）相互印证。

### Anish 的 narrow startups 论题

（[00:30:19]–[00:31:20]）⚠️ **这是他在本库里第一次把这个论题讲完整。**

- **论题本身**：⚠️ **"你现在可以为很少的一群人造出极有野心、极有价值的软件；而我们已经有了人们每月付 200、250、300 美元的先例。所以你可以用几万人做出一个一亿美元年化收入的生意——这在过去基本不存在。"**
- **竞争优势他给了两条**：⚠️ **taste（品味）与 proprietary knowledge（专有知识）**。
  - **taste 的形态**：**"就像一位陪产师可能信奉某一派助产风格，你的个人 agent 也可能信奉某个流派、某种风格、甚至某一套还没被充分理解的经验。而你会去'雇'那个 agent 来给你提供这项服务。"**
  - **专有数据的形态**：**一个只服务纽约市的个人 agent**——"就像有的礼宾有 A+ 的品味、知道所有你会爱的地方，而那很难复制"。
- ⚠️ **他的落点**：会同时发生**主观的专业化**（品味、流派）与**客观的专业化**（专有数据）。

### 商业侧：Amazon 封锁、Shopify 开放，以及"每用户每天 20 美元"

- **三个网的框架**（[00:39:25]）：⚠️ Anish 把 web 分成 **commerce web / application web / content web**——**内容网已经麻烦了一阵子；商务网其实一直做得不错；应用网从 coding agent 发布之后一直在大幅上行。**
- **那周的事件**（[00:39:25]）：⚠️ **Shopify 拥抱 Muse，Amazon 封锁 Muse。**（⚠️ **同一事件在三天前的 [All-In 09-26](20260926-all-in-anthropic-ipo-open-source-flip.md) 已被 Jason 记录过，他的判断是"Amazon 封锁 agent 是战略失误"。本期给的是机制解释。**）
- ⚠️ **Pawlan 的机制解释**（[00:40:25]）：**两家是完全不同的商业模式——Shopify 的重心是让商务民主化，而 Amazon 的钱来自广告收入。"当你把人的眼球移走，整个（广告）体系的目的就被瓦解了。"** 所以 **"如果让 Muse 这些 agent 开始购买、而 Amazon 拿不到任何广告收入，那就把体验里的利润抽走了很多"**——他的推论是 **Amazon 迟早得有一套新范式去在"agent 代人购买"的世界里赚钱**。
- ⚠️ **Anish 补的第二个动机**（[00:43:28]）：**Amazon 大概不只是怕丢广告收入，还怕丢"冲动购物"，以及被去中介化。** 他随即给了一个反问：⚠️ **"我倒很好奇 agent 自己会不会在某种程度上也是冲动购物者——因为 proactivity 意味着 agent 会试图做出讨人喜欢的猜测，而还有什么比惊喜或礼物更讨人喜欢？"**
- ⚠️ **本页认为 Anish 最值得记的一条一般化**（[00:43:28]）：**"这些 agent 不是其主人的完美映射。它们不是完美理性的——它们会是近似理性的，也会以全新的方式非理性。所以我不认为营销、冲动购买、广告这些东西会不再重要，我只是觉得它们需要被改造。"**
- **预订与供给约束**（[00:41:26]–[00:43:28]）：⚠️ Pawlan 提到 **Resy 开始封停使用 browser use 的账号**，理由是"**如果让 agent 瞬间把位子订走，就瓦解了这个以人为导向的预订平台的生意**"。他的设问是：**当所有人都有 agent，大家又回到同一起跑线——那么要么权力回到餐厅手里（按忠诚度或人均消费挑客人），要么进入 agent 之间的竞价。**
  - ⚠️ **Anish 的分析本页单记**：**供给受限**（热门餐桌）与**需求受限**（明天想飞 SF 的人）是两类不同的问题。**餐厅在完美信息下想要的是最高 AOV、跨多次到访的最高 LTV，同时尽量接近 100% 上座——这是一个更复杂的计算。** ⚠️ **他指出当下真正在起作用的东西是摩擦**：**"它依赖终端消费者的摩擦与动机来充当某种防 DDoS 的机制"**，所以 **"专有供给会变得越来越重要"**。
  - ⚠️ **而需求受限侧他给了一条本库此前没有的结构判断**：会出现**团购式的体验**——一组愿意购买的买家聚合起来，供给侧的商家进来竞价。**"我们一直有需求的聚合，但我们从来没有以同样的方式有过供给的聚合，尤其不是在一个让消费者受益的拍卖机制里。"**
- **推荐层**（[00:44:29]–[00:45:30]）：⚠️ Pawlan 的问题是 **"买点白袜子"——外面有两万种白袜子，它并不知道你偏好哪一种**；他认为 **Meta 在这件事上可能有领先（Instagram 与 Facebook 的数据）**。⚠️ **Anish 的反向设想**：这反而可能把长尾和**偶然性**带回来——"我的 agent 回来说：我在 Etsy 上找到一个内布拉斯加的人，她织的白袜子特别棒，要三周，你要吗？"；再往前一步是 ⚠️ **agent 去联系那位织袜子的人的 agent**，"**这就是 agent 对 agent 真正有意思的地方：它们都在代表各自的人行动，有的提供产品、服务、知识，有的去赚钱**"。
- ⚠️ **两人共同落到的一个愿景（本页标注为愿景而不是判断）**（[00:46:31]）：**如果 agent 真的在按产品质量挑东西、而且能自己评估质量，而不是挑营销做得最好或品牌最响的，那激励就被摆正了**；就算按品牌挑，"至少是在用户明确签字同意的前提下——我就是想要 Nike，因为我爱 Nike"。Pawlan 的总结是 ⚠️ **"这打开了一扇门，通向一个真正与消费者对齐的互联网，而这东西我们已经缺了相当久。"**
- **经济账**（[00:47:33]–[00:49:34]）：
  - **Pawlan 的提问带着数字**：122 个里 **65 个收费（35 全付费、30 freemium），只有 13 个完全免费**——⚠️ **"而 Muse 和 Instinct 这两个主导者都是免费的，OpenAI 据说下周还要发点什么。长尾创业公司怎么赢？大佬免费送的时候它们凭什么收钱？"**
  - ⚠️ **Anish 的成本口径（本库第一次拿到这个数字）**：**"按我们的估算，要用真正有野心的方式做这件事，成本大概是每用户每天 20 美元——对一家创业公司可能是一年几亿美元。"** ⚠️ **本库未核实。**
  - **他给的两条可押的方向**：① ⚠️ **browser use 应该会迅速变得指数级便宜**（他承认"如果你今天融资、赌的是六个月内发生这件事，那多少有点在玩胆小鬼游戏"）；② ⚠️ **"我不喜欢把'补贴用户'当成主要价值主张"**——他想看到的是 **"一个每月 1000 美元、而消费者兴奋到愿意付的 agent"**，理由是 **"人们每月在很多非必需品上花 1000 美元，那是欲望"**。
- ⚠️ **一条两人都认同、而且与本库既有材料直接相接的话**（[00:37:24]）：Anish 说 coding agent 很多时候**不是在和人类程序员竞争，因为它们在做没有人类程序员在做的事**（他举自己做的一个"可以走进去的虚拟唱片店"side project——"十年前我绝不会雇人做这个，也绝不会花掉那一年"）。⚠️ **他的落点：**"**这不是关于成本削减，这是关于可能性扩张。**"
