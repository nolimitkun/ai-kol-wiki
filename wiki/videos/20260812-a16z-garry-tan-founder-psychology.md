## 概要

这是本库第一次收录 **YC 现任 CEO 的完整长谈**——此前 YC 只作为别人口中的背景出现。全程围绕一个主题：**AI 把创业的经济学改写之后，创始人该怎么想、怎么组织自己**。

本期最该被单独引用的五条：

1. ⚠️ **"一个 markdown 文件就是一名员工"**（[00:24:08]）——**本库迄今对"skill 文件即组织单元"这一说法最直白的表述**，而且出自 YC CEO 而非某个工具作者。配套的操作法是"**skillify**"：做完一件难事之后，把它变成 markdown + 代码 + 测试，塞进 cron（[00:23:07]）。
2. ⚠️ **"纯按席位计费的 SaaS，不太清楚 5 到 10 年后还存不存在"**（[00:15:06]）——并明确说两年前"12 个月前瞻收入 10–20 倍"还是铁律，"**现在完全不是那么回事了**"。这是本库 [模型商品化/价值捕获](../topics/ai-business-and-value-capture.md) 条线上，第一条来自**早期投资一方**的定价范式判断。
3. ⚠️ **"token maxing"：每年花五到十万美元把 agent 开到满，就等于活在 2028 年**（[00:23:07]）——他给出的机制解释是**前沿实验室对每个请求给你的算力是受限的**，要真正吃满上下文得走 OpenClaw / Hermes Agent 这类自托管 harness，把单请求推到 80 万–100 万 token。
4. ⚠️ **本期最反直觉的一条，也是他自称的"white pill"**：AI 落地的瓶颈"**全是人**"，官僚、中层、七加减二的认知带宽会把一切拖慢——"**社会比你想的慢得多，政府比你想的慢得多，世界上每一家公司都比你想的慢得多**"，所以"**这会花 20 年，而那不是坏事，那其实是好事**"（[00:39:18]–[00:40:18]）。他甚至补了一句在硅谷不讨喜的话：**微软这类公司有结构性护城河，"哪儿也不会去"**。
5. **Brex 的 Pedro 让 agent 读所有直属下属的会议纪要**（[00:29:10]）——本库第一个"**高管用 agent 做组织透视**"的具体案例：他能看到两层以下的冲突在哪，然后带着完整上下文走进一个自己没参加过的会。

## 核心观点

### 一、AI 时代的公司形态：markdown 即员工，loop 即组织

- **skillify 的完整循环**（[00:23:07]–[00:24:08]）：做一次"力量展示"式的难任务 → 把过程变成 **markdown + 代码 + 测试** → 放进 cron job。他的定性是：**"一个 markdown 文件就是一名员工，而且是一名每次都把活干得完美、你要它干多少次就干多少次的员工。"**
- **第一次一定很烂，而且很贵**（[00:24:08]）：关键在于**你能不能非常快、非常简单地说"agent，这儿错了，改掉"**——那条修改轨迹本身会被沉淀成 skill 文件，"**以后再出错就只是修个 bug，然后它就永远在那儿了**"。
- **适用范围是"一切"**（[00:24:08]）：销售、市场、客服，主持人逐个点名，他的回答是"是的，一切"。
- **他自己的实践链条**（[00:16:06]–[00:22:07]）：G stack / G brain（工程侧的 QA loop 与 PM 自动化）→ **Garyslist.org**（自称"agentic newsroom"，为写文章造了个人深度研究的 RAG）→ 从中抽出 agentic RAG 的图生成部分做成 **Soda**（他说效果压过 Memory Palace 等开源方案）。他对这套东西的功能定性是：**"它让 agent 知道，对某个特定任务，该在脑子里留住哪一百万个 token。"**
- ⚠️ **一条被他自己说破的招生渠道**（[00:18:06]）：他把 YC 内部那份"如何劝创始人把野心抬高一个台阶"的 markdown 脚本开源了，但**先让 Claude 把强度削掉 90%**；开源代码深处埋着"来申请 YC"——**"但只有当你是 Claude Code 使用量前 10% 的用户"**，判据是"你是否在想用户、是否对产品与设计有想法"。
- **规模上限的追问与他的回答**（[00:26:08]）：主持人问这套递归自我改进什么时候崩、误差会不会累积。他的答案落在**数据治理**：markdown 一多就是 **provenance（来源溯源）**问题和冲突管理问题——"有两条事实时，有溯源你就能说这条更近、这条赢"——**需要一个 cron job 定期扫过去，确保东西是准的、来自对的地方**。
- **规模数字**（[00:26:08]）：他说现在有公司"**两三个人 + 几百个 skill 文件、上百个 agent，四个月从 0 做到 1500 万美元 ARR**"。⚠️ 转述、无公司名、无外部验证。

### 二、token maxing：用钱买时间差

- **机制解释**（[00:22:07]）：ChatGPT / Claude 这类前沿产品**"在算力上仍然相当受限"**——不是模型不行，是他们愿意给单次请求的算力有限。要"token max"，就得用 **Hermes Agent 或 OpenClaw** 这类自托管 harness，"**一路调到满**"，让单请求装进 80 万到 100 万 token，并把这些写进你的 `soul.md`。
- **价码与收益**（[00:23:07]）：**"一年大概花五万或十万美元，把 agent 开到全强度、每个请求都是满格 150 IQ……但你会立刻感受到。对一个 CEO 或创始人来说这非常划算。你得允许自己这样烧 token。"** 他的说法是**这等于活在 2028 年**。
- ⚠️ **与本库既有材料的关系**：这是"**用资本换能力提前量**"的明确表述，与 [Kavak 每天实例化十万级 agent](20260810-a16z-kavak-agentic-company.md) 是同一现象的两端——Kavak 是公司层面的规模化，这里是**个人层面、可当年付费买到的**。

### 三、组织：中层应该是 agent，API line 会消失

- **7±2 是所有组织的物理上限**（[00:30:12]–[00:31:12]）："世界基本上是围绕人建的，而人在任何时刻只能在脑子里放七加减二样东西。" 他的推论是**政府尤其没准备好**，而"**你加上一个 agent，能在脑子里放下三本《哈利·波特》**"。
- **Brex 的具体做法**（[00:29:10]）：Pedro（Brex 高管）先解掉了合规顾虑——**开源了一个叫 "Craptrack"（照录转录稿拼写，⚠️ 未核实）的层，用一个 agent 监视 OpenClaw 的全部网络流量和动作**，理由是"Brex 是监管最严的金融科技之一"。解掉之后的用法是：**agent 读所有直属下属的会议纪要**，看到两层以下哪里坏了、谁和谁在冲突；他可以**带着某个合规团队过去三周的完整上下文，走进一个自己没参加的会，说"其实你是对的，我们按你的方式做"，然后离开**。
- ⚠️ **主持人推到更远的一步**（[00:36:15]）：Anish 的表述是"**中层官僚应该是 agent**"——高管层定方向、个人决定执行、"**但整个组织协调层，历史上很多产品经理在做的那件事，不应该是人**"。Garry 没有反对，接着讲了 API line。
- **API line 会被抹掉，而不是让你往上爬**（[00:37:16]）：他先复述 Venkatesh Rao 的框架（Uber 司机在 API line 之下，你该努力爬到线上），然后说**"我其实认为 AI 抹掉了这条线"**。他的证据是被投公司 **Kolabtree（⚠️ 拼写照录，未核实）发布了一个不给人用、只给 agent 用的 bug 上报端点**——agent 报了 bug，另一端**实时回复**："这是个好 bug，我们记下了，下周修，同时你可以试试这个绕法。"他说这个画面他一直忘不掉：**公司之间可以这样一来一回，而不是线下的人被动照 API 说的做**。
- **丰田生产方式的类比**（[00:38:17]）：80 年代日本车变好靠的是管理技术——**在线上干活的人应该被允许改这条线，因为他掌握最多上下文**。他把这条当作"AI 让一线拿回决策权"的历史先例。
- ⚠️ **他与主持人在这里有一处措辞上的分工，本库照记**：Anish 把管理阶层称作"**从创始人模式起算的一百年弯路**"（[00:33:13]），Garry 的回应更温和——他不认为当年那个产品经理"想浪费我们的时间"，只是"**一天没有那么多小时，我们是极其有限的人**"（[00:35:15]）。他讲的是 22 岁在 Windows Mobile 时，为一个 P3 bug 跨过高速公路去 Windows 团队、同事**带了根棒球棍**当模糊威胁的事（[00:34:14]）——"**微软那样的组织大概做不到，但创业公司可以。而且每家创业公司都必须。**"（[00:36:15]）

### 四、创业范式的判断

- ⚠️ **SaaS 的定价范式失效**（[00:15:06]）：**"你不能就做个 SaaS 了……纯按席位的 SaaS，不完全清楚它 5 到 10 年后还存不存在。作为楔子完全没问题，但如果你 2026 年在做这个，你最好指望它能跳到某种数据或网络效应的护城河上。"** 他补充说两年前"SaaS 是神，前瞻 12 个月收入 10–20 倍是铁律"，"**现在完全不是那么回事了，很难相信**"。
- **共同创始人这条 YC 铁律正在松动**（[00:14:06]–[00:15:06]）：他先给出为什么一直坚持共创——引 Derek Sivers 的 TED 演讲，**"一个人在田里跳舞是疯子，是第二个人加入才让它变成派对"**，而"一个说服不了任何人加入的一人邪教，比邪教还糟，就是个疯子"。但"**vibe coding 和 agentic coding 让任何一个人都能变成 400 个自己**"，所以"**我们正处在一次大转型中间**"。
- ⚠️ **由此得出的年龄结构判断，是本库这条线上第一条**（[00:27:10]）：**"35、40、45 岁、见过世面、建过很多公司的创始人是一个大趋势"**——因为"**把这样一个人乘以 400，你可以跑赢 Mag 7 里任何一整个部门**"。他点名 **[Peter Steinberger](../people/peter-steinberger.md) 是完美例子**。⚠️ 他同时说"Patrick Collison 那样的人不会变少"，即这是**增量而非替代**。
- **代码不再珍贵**（[00:16:06]）：过去为了把东西发出去要经历的一切，逼得你必须觉得自己做的东西是"大写的 Important"；现在"`/QA`，完事了，我们测过了，90% 覆盖率"（[00:19:06]）。他的推论是**agency 与品味的重要性爆表**，而且**这两样不是天生的，是练出来的**（[00:19:06]–[00:20:06]）。⚠️ 主持人在这里给了正面挑战（引 Nikita 的说法）：**电影和软件人人都能做了，可干这行的还是原来那 20%**。Garry 的回答是拿自己当反例——他自称大器晚成，靠的是**犯错 → 反省 → 换选择**。

### 五、判断的方法论：不要 LARP

- **他的两次"错过"是全篇的支点**：2003 年在 web 最被唱衰的时候离开 web 编程去做 Windows Mobile（[00:02:00]）；以及 Peter Thiel 当面开出一张 7 万美元的支票（等于他当时在微软的年薪）叫他加入后来的 Palantir，他回答"谢谢您 Thiel 先生，但我今年可能会升到 60 级"——**"我确实升了。……以现在算，那是个 20 亿到 40 亿美元的错误。"**（[00:08:03]）
- **他从中提炼的判据**（[00:04:01]、[00:09:04]）："什么最热、我该做什么"**是错的问题**，对的问题是"**你对什么感兴趣？你独特地知道什么？**"；他把两次犯错都归因于**"按地图走，而不是低头看地形"**。
- **"不要 LARP"**（[00:02:00]–[00:03:01]）：这条 meme 的内核是**真诚（earnest）**，而真诚的实质是**勇气**——"如果有人反驳你，甚至一篇博客或推特上的谁反驳你，你可以说：我不同意，因为我相信我的直接经验。"
- **有意思的事情找不到边缘**（[00:06:03]）：主持人给的判据——"好东西的一个好度量是你能不能找到它的边缘。最有意思的那些，你通常找不到；就算找到了对话的边缘，也找不到智识上的边缘。"Garry 接的是硅谷的老图景：**Homebrew Computer Club 不是你能约到会的地方**，做出"每个桌上一台电脑"的是**边缘的怪人朋克**（[00:05:02]）。
- **"我生命里所有牛的东西都有点像邪教"**（[00:10:05]）：定义是"**始于某种与正统相悖的真理或信念**"，而这很朋克。他把 Palantir 的洞见归结为"未来已至，只是分布不均"，而**第一性原理的知识只能靠下到实验、或去找第一手经历那件事的人拿到——那才是 gnosis（秘传知识）**。

### 六、下一台计算机与消费 AI

- **形态**（[00:41:19]–[00:42:19]）：短期还长这样，但"**这个形态显然待不住，很明显会是语音**"；记忆是关键，"我不觉得大家长期会满足于 ChatGPT 或 Claude Cowork"。他要的那个东西的描述带文学性：**"由仁慈机器照看的一切"——它知道你的希望、恐惧与欲望，锲而不舍地朝那个方向帮你。**路径是 computer use、记忆、**diarization（说话人分离）**、摄取。
- ⚠️ **一条时间点预测**：**"我猜明年，2027，会是 harness wars（harness 之战）。"**（[00:42:19]）他说现在没人在谈这个，而且**它本质是成本问题**——今天前沿模型的纯算力，"两三年后大概是 50 或 100 块钱"，那时候会有**一场争夺十亿消费者的战争**，"**浏览器大战会重开**"。
- ⚠️ **主持人给出的价格结构判断（本库应单记，因为它是一句可证伪的机制陈述）**（[00:43:20]）：**"前沿的每 token 价格正在趋向无穷——我的论点是无穷美元一个 token，你拿不到；而一周前还是前沿的那个模型，每 token 价格正在塌向零。"** Anish 认为这是大 white pill，理由是**消费产品普遍免费试用，而免费试用要求边际分发成本为零**——"我们有了 40、50 年来第一次有情感质感的计算机，**而我们还没造出更有野心的消费产品，这是个悲剧**"。
- ⚠️ **他对自己判断的一次公开修正**（[00:44:20]）："成为 OpenClaw 的皈依者让我非常确信这事会马上发生，**而现在我觉得那完全不对**。" 本库把这条与他"20 年 white pill"并列——**同一个人在同一集里给出的两个速度判断是自洽的：能力已到，扩散很慢。**

### 七、地方政治与"值得一试的乌托邦"

- **被追问"你们科技圈是不是想造乌托邦"时的回答**（[00:32:12]）：他先说"这是个陷阱"，然后正面接："**我们也许永远造不出乌托邦，但去尝试是值得的、配得上的**……我不会说硅谷或科技会实现乌托邦，我会非常真诚地说，**我们在试图带来一个更好的世界**。"
- **旧金山那段的个人起点**（[00:46:21]）：他把自己介入本地政治归因于两件同时发生的事——疫情期间对亚裔长者的恶性犯罪被地检睁一只眼闭一只眼，以及**学区公开敌视想在公立初中学代数的亚裔孩子**。他说这一条"让它变私人了"：**他自己就是东湾 Fremont 的公立学校孩子，初中不能学代数就学不到微积分、就读不了斯坦福工程**。
- ⚠️ **本库对这一节的处理**：这一段（[00:45:21]–[00:50:23]）是**美国本地政治议题**，与本库主题相关的只有两条可迁移的判断——① 他认为"**一切都在媒体的下游**"，机构失灵时"**当系统变得如此可憎，你就得把身体压上去**"（[00:47:22]–[00:48:23]）；② 他给出的可外推版本是"**act local**"：**"你不必用美国的方式想象 AI 如何影响你的社会。如果你想让 NHS 变得了不起，你可以用这个技术做到。"**（[00:49:23]–[00:50:23]，这句由 Anish 说出，Garry 接"是的，act local"）。**其余具体政治指控本库不转述、不裁决。**

## 与本库其它观点的关系

- **"markdown 即员工"与 [Peter Steinberger 的 OpenClaw](../people/peter-steinberger.md)**：Garry 不仅点名 Peter 是"35–45 岁创始人"的完美例子（[00:27:10]），还说**是 Brex 的 Pedro 把他带进 OpenClaw 的**（[00:28:10]）。本库此前关于个人 agent 的材料主要来自作者与部署方，**这是第一次由 YC CEO 从"这该成为组织默认形态"的角度背书**。
- **与 [Kavak（a16z，2026-08-10）](20260810-a16z-kavak-agentic-company.md) 的两处正面咬合**：① Ali Massa 说"**人们还在用专家式多 agent 系统**"、他改用有硬目标的长期 agent；Garry 的 skillify + cron 是**更保守的一侧**（仍然是流程沉淀），两条路线在同一频道相隔两天出现，**本库并列不裁决**。② Kavak 的 RSI 重定向是"**自我改进的组织**"，Garry 的 provenance + cron 扫描是**这个说法在数据治理层的具体化**——本库认为这两条应互相引用。
- **与 [Benedict Evans 的价值上移](../people/a16z.md#benedict-evans独立科技分析师前-a16z-合伙人)**：Garry 的"纯席位 SaaS 可能消失"是同一命题的**定价机制版**，但落点不同——Evans 说价值往上游走，Garry 说**你得跳到数据或网络效应的护城河上**，即价值仍可能留在应用层，只是计价方式必须换。
