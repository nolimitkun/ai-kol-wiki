## 一、底层事实：VGS 在做什么，以及为什么这个位置在 agent 时代变值钱

### 它是什么（[00:02:01]–[00:09:05]）

- **业务**：**独立的支付凭证金库（vault）**。商户不想自己碰 16 位卡号（PAN），VGS 负责捕获、加密、保管，并在需要扣款时把凭证交给支付处理方。✅ **商户因此可以把 PCI 合规"移出范围"**（[00:11:08]）——他说 PCI 文档"上次读的时候超过一百页"，而**"Visa 和 MasterCard 可能是敌人，但在这件事上他们一致"**。
- **十年里发生的变化**：现在主流不是存 PAN，而是向发卡网络（Visa / MasterCard / Amex / Discover）换一个 **domain-bound 的网络 token**——**只在你这个商户域名上能用**，泄露了也用不到别处（[00:04:01]–[00:05:01]）。
- ⚠️ **为什么是"独立"金库很重要**（[00:06:02]–[00:09:05]）：年流水 10 亿美元以上的商户**平均有 3–5 家支付处理商**（为了费率、通过率、地区做分流）。**每多一家处理商，保管与更新的工作就乘一遍**——"我可能有一亿张卡，但得在 Chase 存一亿、Stripe 存一亿、Braintree 存一亿"。
- ⚠️ **他给的卡片周转率**（[00:07:03]）：**每年约三分之一的卡会换号**——**25% 来自四年有效期的数学必然**，另约 **5%** 来自并购、欺诈等。⚠️ **主持人自己的 Capital One 卡因 Capital One 收购 Discover 而换号、随后不断收到商户扣款失败通知，被两人当作这条的实例。**

### 自述的规模（⚠️ 全部未核实）

- **"约三分之一的电商 GMV 的凭证由我们保管"**；客户含**最大的在线商户、最大的新型银行、以及最大的前沿实验室**（[00:00:00]、[00:02:01]）。
- **"我们有大约 100 亿条凭证"**（[00:27:16]）。
- ✅ **本页记一处值得注意的不回答**：主持人直接问 **"你们见过/存过的美国卡占比是不是 80%？"**，⚠️ **嘉宾没有确认那个百分比，而是改口给了"100 亿条凭证"这个绝对数。本页照录这个回避，不把 80% 当作任何人的断言。**

### 主持人自己给的定性

（[00:26:16]）**"VGS 是一门非常无聊的生意……干金库这行，你的工作就是不刺激、安全、可靠。"** ✅ **本页认为这句话值得保留，因为本期的核心论点恰恰是"这门无聊生意因为 agent 变成了战略位置"——而这正是利益相关最集中的地方。**

## 二、⚠️⚠️ "从观众到演员"：本期的中心论断

（[00:00:00]、[00:12:09]–[00:13:09]）嘉宾的原话：

> **"过去三个月里，我们经历了一次巨大的跃迁：agent 从我称之为观众的东西，变成了演员。因为它们实际上长出了手脚——而手脚就是支付凭证。"**

- **他给的个人例子**：给 7 岁儿子找钢琴老师——要匹配孩子每周三天足球课的日程、老师的日程、还要能上门。**"我之前问过 ChatGPT，拿到的是一些推荐；而就在昨晚我问了一个 agent，它把整件事办完了"**——找人、反问几个问题、核对日程、订下第一节课。
- ⚠️ **他给的判据，本页认为比"能力提升"这个说法更可操作**：**"这比又往我门口扔一个任务要有用无限倍。"** ✅ **即分界不在模型能力，而在"交付的是建议还是已完成的交易"。**
- **由此他给出本期的第二个命名**：**"钱包战争（wallet wars）"**——**每个钱包现在都在抢着接到 agent 上**（[00:13:09]）。

### 钱包战争的筹码（⚠️ 以下数字全部由他口述，本库未核实，[00:13:09]–[00:14:09]）

| 钱包 | 消费者侧 | 商户侧 |
|---|---|---|
| **Stripe Link** | 约 **3 亿** 账户 | 约 **100 万** 商户 |
| **Shop Pay（Shopify）** | 量级相近 | 约 **170 万** 商户 |
| **PayPal** | **4 亿以上** 账户（⚠️ 他自注"取决于怎么口径"） | 约 **3000 万** 商户 |

- **agent 要的两件事**：**已有凭证的消费者数量** + **商户覆盖广度**。

### ⚠️ 两人把它接回了一场打了十五年的旧战争

（[00:14:09]–[00:16:09]）主持人指出**钱包战争早就打过**（他点名 Visa 的 **V.me**、**Google Checkout** 等失败尝试），并给了旧战争的经济学：

- **"成为默认存储凭证"价值极高**——他称之为被**巴甫洛夫式训练**："我一看到花，我就用 PayPal。"
- ⚠️ **嘉宾给了一个本页认为最有价值的历史数字**（[00:16:09]）：他在 Visa 时期，**发卡行（如 Chase、Amex）为了在 Uber、Airbnb 这类平台上成为默认卡，付出过"数千万美元"**。
- ✅ **两人由此区分出两层战争**：**卡组织/发卡行之间争"钱包里的第一张卡"**，与**钱包之间争"结账页上的那个按钮"**（主持人说结账页"长得有点像 NASCAR"，满是赞助商按钮）。⚠️ **他们的判断是 agentic commerce 加了第三层，而不是替换前两层。**

## 三、⚠️⚠️ 那把吊灯：一次真实失败，以及它暴露的两处制度断裂

来源：[a16z / VGS](20261015-a16z-vgs-agentic-tokens-wallet-wars.md)

✅ **本页认为这是本期最该被完整记下的部分，因为它是本库 agentic commerce 材料里第一份带失败细节的实地记录，而不是前瞻判断。**

### 他先给了一个定性（[00:19:12]–[00:20:13]）

> **"Stripe 在很多方面就是 agentic commerce 的 AOL。"**

⚠️ **他明确说这是褒义**：**他们想出了让 agentic commerce"就是能用"的办法，代价是一种围墙花园式的做法。** ✅ **本页认为这个类比值得保留，因为它同时给出了优点（现在就能用）与预期（会被开放标准取代）。**

### 事件经过（[00:20:13]–[00:21:13]）

他要为家里的活动买户外灯，让某个消费侧 agent 去找，**agent 在 Walmart 找到了并装满了购物车**。⚠️ **但 Stripe Link 没有和 Walmart 的连接**——Link 有他的卡，却**不能把卡直接交给 agent 再交给 Walmart**。

**Stripe 的处理方式**：**代他买下**——自己签发了一张 **Visa 一次性虚拟卡**完成在 Walmart 的付款，**然后作为第二笔交易向他本人收款**。⚠️ **他把这个结构类比成 DoorDash**（你付 DoorDash 100 块，配送员再去付餐厅）。

**结果**：✅ **东西到了，金额对了，交易成功。**——⚠️ **本页强调这一点：这不是一次失败的购买，而是一次成功的购买里埋了两处制度断裂。**

### 断裂一：退单找不到商户（[00:21:13]–[00:22:14]）

如果吊灯有问题，他会打给发卡行 Capital One 说"我和 Walmart 的这笔交易出了问题"——**但银行账单上没有 Walmart，只有 Stripe**。

⚠️⚠️ **他讲的那个测试期真实案例，本页认为是全期最有说服力的一个细节**：有人用 Amex 走了同样的流程后致电 Amex，**Amex 只看得到 Stripe，于是给了一个电话号码让他联系"这个 Link 商户"**——**那个号码直接打到了一位 Stripe 工程师的手机上**。他的解释是 **Stripe 的架构本来就不是为了处理退单（chargeback）而设的**。

**主持人给的制度层解读**（[00:22:14]–[00:23:14]）：

> **"Visa 和 MasterCard 之所以有这么坚不可摧的位置，正是因为它们居间一切、并且制定规则——而退单非常重要。"**

- ✅ **他把退单定性为信任机制**：我付了钱你不发货，**存在一套规则让我投诉、并有一个中央中介相对公平地裁决**。他指出**这对商户同样有利**，因为消费者因此更敢下单。
- ⚠️ **他顺手用这条切了加密货币**：**加密支付是无记名工具，付出去就拿不回来**——"这既可以是 bug 也可以是 feature，但对吊灯这个例子，你会希望 Visa 和 MasterCard 在中间"。✅ **本页标注：这条与本库 [Coinbase 的稳定币 agentic commerce 路线](20260910-no-priors-brian-armstrong-agentic-finance.md) 正面冲突，见第四节。**

### 断裂二：商户拿不回客户关系（[00:24:14]–[00:25:14]）

买完之后 Walmart 给他发邮件：你付了 6.99 美元的配送费，**要不要订 Walmart Plus，今天订就把配送费抵扣进去**。他点了同意——**交易失败，因为 Walmart 手上那张卡是 Stripe 的一次性卡**。

⚠️ **嘉宾给的是规范层的解读，不是技术层的**：

> **"电商的规范之一是，Walmart 花了很多钱才把我变成客户，他们就有权利尝试和我建立关系、向上销售、交叉销售。"**

✅ **本页认为这条比断裂一更值得注意**，因为它说明 **agent 代付不只是"谁承担风险"的问题，它还切断了商户侧的获客经济学**——⚠️ **而商户是否配合 agent，恰恰取决于这笔账。这条直接接上第五节 Amazon 为什么封锁 agent。**

## 四、卡组织的答案：agentic token，以及它与稳定币路线的对读

来源：[a16z / VGS](20261015-a16z-vgs-agentic-tokens-wallet-wars.md)

### 机制（[00:23:14]–[00:25:14]）

卡组织推出了一类新标准，他称之为 **agentic token**，让钱包能**安全地把凭证交给 agent、agent 再交给商户**，而**被扣款的仍是消费者本人那张卡**。流程要素：

- **agent 必须先在 Visa / MasterCard / Amex 注册**（[00:32:20]–[00:33:20]）。
- **交易前 agent 声明上下文与约束**：**"我要发起一笔交易，我是经过验证的 agent，我花不超过 100 美元。"**
- **token 本身"不过是一个新的 16 位数字"**，安全地给 agent，agent 给商户，商户照常跑交易。
- ✅ **它解决的正是第三节那两处断裂**：**保住了退单规则，也保住了后续交易（即商户与消费者的关系）。**

### 自述的采用量（⚠️ 未核实，[00:25:14]–[00:26:16]）

> **"三个月前这是零，它根本不存在。……现在我们每周做几百万枚这样的 token。"**

他称 **VGS 是"目前为止最大的 agentic token provisioner"**，三侧（agent、钱包、部分商户）都做。⚠️ **本页提醒：这是本期利益相关最集中的一句，"从零到每周数百万"的增速叙事与他的业务位置完全重合，本库按业务叙述收录。**

### ⚠️⚠️ 与本库既有材料的路线之争，本页认为必须并列

| | 对"agent 怎么付钱"的答案 | 它给的理由 | 它的代价 |
|---|---|---|---|
| ⚠️ **本期（卡组织轨道）** | **agentic token**：agent 向卡组织注册，拿到带额度与上下文约束的域内 token | **退单与争议裁决是信任机制，不能丢**（[00:22:14]–[00:23:14]） | 需要注册、需要卡组织居间；⚠️ **本期未讨论费率下限** |
| ⚠️ **[Coinbase / Brian Armstrong，2026-09-10](20260910-no-priors-brian-armstrong-agentic-finance.md)** | **稳定币 + x402**：绕开卡轨道 | ⚠️ **卡组织最低费用约为 30 美分固定 + 百分比，所以低于 1 美元的交易在结构上不成立**；而他们看到的 agentic commerce 交易**约 76% 低于 30 美分** | ⚠️ **无记名工具，没有退单**——正是本期主持人点名的那条 |

⚠️⚠️ **本页的读法（综合，不应归给任何人）**：**两条路线其实在回答不同场景的问题，而双方都没说这一点。** Coinbase 的数据讲的是 **agent 向 agent / API 买信息的微支付**（76% 低于 30 美分）；本期讲的全部是 **agent 替人买实体商品与服务**（吊灯、酒店、钢琴课，金额在数十到数百美元）。✅ **在前者上，退单机制几乎无意义而费率下限是死结；在后者上，费率可忽略而退单是刚需。本库因此不判定两条路线谁对，而建议按交易金额分段引用。**

### 金库从单人变多人（[00:28:16]–[00:29:18]）

他给的概括：**"金库正在从单人游戏变成多人游戏，而这让它们值钱得多。"** 两个例子：

- **商户侧**：商户有多家处理商，金库就同时是每家处理商的金库。
- ⚠️ **前沿实验室侧**：**一家大型前沿模型公司原本保管卡只是为了收订阅费（单人）；现在 agent 要用同一张凭证去付款（多人）。**
- **他顺手类比 1Password**：从个人密码库变成要授权给多方的东西。

## 五、⚠️⚠️ 三步交易框架，以及第三步在 agent 上无解

来源：[a16z / VGS](20261015-a16z-vgs-agentic-tokens-wallet-wars.md)

✅ **本页认为这是本期最可迁移的一条，因为它不依赖 VGS 的市场地位，而且给出了一个明确的"目前无解"。**

**主持人给的旧世界三步**（[00:29:18]–[00:31:19]）：

1. **这张卡是真的吗？** 先是 **mod 10 校验**（判断是不是合法卡号格式），再向银行核验是不是真实存在的卡。
2. **我面前这个人是卡主吗？** 他举 25 年前买贵重物品的场景——**店员核对卡背签名、并要求出示 ID**。
3. ⚠️ **"你神志清醒到可以做这笔交易吗？"** 他说这一步**"你大概只在拉斯维加斯见得到"**：卡是真的、ID 也对得上，**但你要是喝了 15 杯话都说不清，赌场大概不会让你付款。**

**映射到 agent**（[00:31:19]–[00:33:20]）：

| 步骤 | agent 时代的状态 |
|---|---|
| ① 卡是不是真的 | ✅ **"已解决的问题"**（主持人原话） |
| ② 对方是不是有效持卡人 | ⚠️ **互联网时代本来就难**（"签名照片是什么意思？你是个 IP 地址"）；**agentic token 的 agent 注册机制是针对这一步的答案** |
| ③ ⚠️⚠️ **它神志清醒吗 / 它有没有产生幻觉** | ⚠️⚠️ **嘉宾明说：**"这部分我认为我们还没有完全搞清楚。" |

**第三步为什么难**（[00:33:20]）：他举自己给女儿体操比赛订圣地亚哥酒店、限价 500 美元的真实指令。**卡组织可以验证"这确实是你的 agent、这确实是你的指令"，而且新标准要求 agent 给出上下文（"这是一笔酒店预订，金额是多少"）**——⚠️ **但"我很难知道你有没有把日期订对"。**

> **"如果 agent 犯了错，而卡组织该做的都做对了……那么那套争议机制就是未解的。但我认为我们会走到那一步。而且很可能 agent 得承担一部分责任。"**

### 责任归属：主持人把它推到了更硬的地方

（[00:33:20]–[00:35:23]）主持人提出 **delegated authority（授权委托）**，并给了商户侧的立场：

> **"商户不会在乎'你订错了酒店房间'。你给了卡，你把权限委托给了一个 AI agent、或者你的人类助理、或者你配偶——我不管。我在收钱，最后不能有借口。"**

- ⚠️ **他把它接到一个支付业既有概念上：friendly fraud（友好欺诈）**——消费者**并非没收到服务，而是因为花得太难堪而否认交易**（他举了"在某个游戏里花一万美元买虚拟宝石"的例子，并明确声明那不是他本人）。
- ⚠️ **他点出旧世界的道德风险**：小额交易**银行往往懒得争，直接退给消费者**，"这本身制造了道德风险"。
- ⚠️ **他给的 agent 时代版本**：X 上已经能看到**"你什么意思，你花了 900 美元，你这个蠢货"**这类帖子——**那这笔退单该由谁承担？**
- ✅ **他给的一个可能解**（[00:34:21]）：**如果两个 agent 在竞争你的生意，承担责任本身可以成为卖点**——"我会替你兜底"。⚠️ **这是推测，不是已发生的事，本页按推测记录。**

## 六、商户会不会配合：Amazon 封锁、三类商户，以及开放银行的前例

来源：[a16z / VGS](20261015-a16z-vgs-agentic-tokens-wallet-wars.md)

### ⚠️ 主持人对 Amazon 封锁 agent 的解释，以及他主动给的限定

（[00:35:23]–[00:36:25]）**Amazon 封锁了某个消费侧 agent**。他的解释：

> **"主要是因为 Amazon 是一家广告公司，他们要的是你和你的眼球去他们网站。他们不要你的 agent，因为你没法变现 agent 的眼球——agent 没有眼球。"**

⚠️⚠️ **他紧接着自己加了一条限定，本页认为这是他本节最该被引用的地方**：

> **"我觉得说'任何对抗 agent 的人都是卢德分子、都完蛋了'是一种过度简化。Amazon 有理由，有真实的财务理由去对抗——因为广告比单纯卖货赚钱得多。"**

✅ **本页标注：本库 [AI 商业与价值捕获](../topics/ai-business-and-value-capture.md) 上关于"在位者抵制 agent"的材料多半默认抵制是短视的；这是第一条明确说抵制可以是理性的、并给出了具体收入结构理由的表述。**

- ⚠️ **他同时指出 VGS 两头都能做生意**："既帮接纳方做接入是高价值的，**同时帮对抗方把 agent 流量过滤掉也是高价值的**。"✅ **本页认为这句对理解本期的立场很重要——嘉宾公司在这场冲突里是中立收费方。**
- **他给的竞争后果**：商户如果**插 15 道验证码**，agent 就会去找那个接纳它的商户，"你肯定会走接纳 AI 商务的那一家"。

### 嘉宾的三类商户分法（[00:36:25]–[00:37:28]）

> **"Amazon 那边也许是恐惧，Walmart 那边也许是贪婪，而 SMB 那边也许是别无选择。"**

| 商户 | 动机 | 他给的理由 |
|---|---|---|
| **Amazon** | **恐惧** | 实质是广告生意 |
| **Walmart** | **贪婪** | ⚠️ **目前没有封锁**；"如果你是地球上最大的零售商之一、有最好的最后一公里配送，这对你全是好事" |
| **Shopify 伞下的大量小商家** | **别无选择** | 这很可能是一条**关键的新渠道** |

### ⚠️ 开放银行作为前例：他对结局的预测

（[00:37:28]–[00:39:29]）他把核心问题提成一个**权利问题**：

> **"作为 Amazon 的客户，我有没有权利把我的登录委托给一个 agent？而 Amazon 有没有权利说不？"**

**他给的前例是 Plaid 与 Chase 等银行的开放银行之争**，而**结局不是任一方全胜，是一场漫长的谈判式和解**：

> **"Chase 最后说的是：你确实有权拿到这些信息，但只能走我的 API。而我的 API 限制我给你多少信息、把银行账户 token 化，而且我可能会为此收你一笔钱。"**

- ⚠️ **他对 agentic commerce 的预测是同构的**：会有**欢迎 agent 的商户**，也会有**自己上 agent 的商户**。
- ✅ **他给的一个本页认为很准确的区分**：**Chase 那次主要是安全与控制之争；而 Amazon 这次是"我是一个有观点的 API"**——我基于关于你的大量数据，**对你该买什么有意见**；而你的 agent 对你想要什么也有意见。**"那将是一场精彩的对抗，或者说对话。"**
- **他的日常类比**：去 Best Buy 买电视，**店员的工作是帮你，但他的工作也是拿提成**。
- **落点**：**"最后我认为消费者多半是赢家，但我们不知道那会长成什么样。"**

## 七、⚠️⚠️ 主持人的不对称性论证：给 agent 消费红利装一个时间上界

来源：[a16z / VGS](20261015-a16z-vgs-agentic-tokens-wallet-wars.md)

✅ **本页认为这是全期最该被本库长期引用的一条，而且它来自主持人、与 VGS 的业务无关。**

（[00:43:32]–[00:45:34]）他先给了机制（[00:43:32]）：

> **"高价格的解药就是高价格。如果因为你得早上七点打电话所以很难订到餐厅位子，那么现在每个人都有一个七点打电话的工具了。"**

结论是**头五个拿到工具的人有了一件了不起的工具，最后五个人面对的是"太挤了，没人去那儿了"**。

**他由此给当下的 agent 消费侧胜利定性**（[00:43:32]–[00:44:33]）：

> **"现在这些早期的胜利——'哦它帮我省了钱、它办成了这件事'——都是因为不对称性。极少数人有这个工具，而商户或者对手方根本不知道发生了什么。"**

⚠️⚠️ **他随后给了这条的反向推论，本页认为是本节的真内容**：他预期**对手方会反过来拒绝 agent**——

> **"我等着有一天 Comcast 说：我们知道这不是你。让 Alex 来接电话，我不会把东西给他的 agent。"**

- ⚠️ **而这件事已经在发生**（[00:44:33]）：他自述 **Comcast 已经按 IP 封锁了他用的那个 agent**，所以他改用 **Codex / Astra 在自己电脑上登录**去办事。✅ **本页标注：这是本期第二个"商户已经在主动封锁 agent"的一手实例（第一个是 Amazon），而且这一个的应对方式是 computer use——即封锁把 agent 从 API 层逼回了像素层。** ⚠️ **可与 [Greg Brockman 对 computer use 的论证](20261015-no-priors-greg-brockman-cyber-spend-drug-physics.md) 并读：他说走屏幕像素 + 键鼠这条人类同款接口的好处，正是"任何能用电脑做的事都直接落在分布内"——这里成了绕过封锁的实际手段。**
- **他的落点**：**"你没法把它无限放大，因为世界会适应。"**

### ⚠️ 配套的第二条：breakage 模型会垮

（[00:45:34]–[00:46:35]）嘉宾给了同一方向的另一个机制。他先举自己的例子：**想买一张刚好卡在能升舱价格线上的机票，"这事挺难，我常常买过头，而我的 agent 做得完美"**。然后：

> **"卡的积分之所以存在，是因为我在餐饮上给你一个很大的头条奖励，但你同时也会把钱花在加油上。如果 agent 居间了我们所有的交易，而我只在拿得到积分的那张卡上刷——整个积分奖励生态就垮了。"**

⚠️⚠️ **他给的一般化表述，本页认为可以直接迁移到别的行业**：

> **"任何带 breakage 模型的东西，都会开始垮掉。"**

（breakage = 商家按"一部分权益不会被兑现"来定价的模式：过期积分、忘记取消的订阅、没人读的条款。）✅ **他的落点是中性的**：**"然后我们就得有新的条款。也许更好，也许更糟，我不知道，但肯定会不一样。"**

## 八、过誉与低估

（[00:39:29]–[00:43:32]）

**主持人的总则**（[00:39:29]）：**"硅谷高估一切，而世界其他地方低估一切。"** ⚠️ **他给的配套观察是人们的印象停在旧版本上**——他举自己 2017 年那台 Model 3 的自动驾驶"完全不能用，是个笑话"，所以换车后对新版本一直抱怀疑；**同理，在 2022 年试过 ChatGPT 的人会觉得那是个写诗的玩具**。

**嘉宾的过誉**（[00:40:29]–[00:41:31]）：⚠️ **"我不认为我们会迎来 agent 把存款在账户之间搬来搬去追收益、导致储蓄挤兑的局面。"** 他的理由是**摩擦足够多**，并用自己举例：他明知 Mercury 的储蓄利率更好、理应把钱放那边再在付账单前挪回 Chase，**但 Chase 的账单支付就是更好用、集成更多、设置都在那儿**。

**嘉宾的低估**（[00:41:31]–[00:43:32]）：**大量未被变现的需求**。

- ⚠️ **他的例子**：一个骑行 WhatsApp 群里有位朋友每隔半年会根据滚动阻力推荐新轮胎，**他每次都想"我该买"，但实际两年才买一次**；**"如果我的 agent 在那个群里，每次推荐我都会买。"** 主持人的接话是 **"那你在自行车装备上严重变现不足"**，他的落点是 **"Alex 身上会有更多 GDP 被挤出来"**。
- **同时他说 agent 也会替人省钱**（取消忘了的订阅、试用期）——**"agent 会同时帮我们省钱和花钱。"**
- **他的根据**：**"据我所知，人的欲望和需求是无限的。"** ⚠️ **本页标注这是一句无支撑的一般化断言，但它恰好是整期商业论证的前提，本页照录并标明。**

## 九、VGS 的三个时代（自述的战略叙事）

（[00:47:36]–[00:49:37]）⚠️ **以下全部是公司战略自述，本页按此记录。**

1. **金库时代**：十年时间成为互联网上最受信任的凭证存储。
2. **更新时代**：三分之一的凭证每年要更新，**而每个卡组织有自己的更新标准、还各自造了多种网络 token**——"如果只是存信息那是一回事，但你得存它、还得从网络拿一串 token 让数据保持刷新"。
3. ⚠️ **网络时代（他说现在刚开始）**：**按规则在多方之间居间撮合凭证**。他说 VGS 同时在**发卡行侧做 token 化**——**"如果你既在 token 化卡、又在保管卡，你就站在这个生态的两边"**，于是可以做前面说的那些信息互换。

**他的落点**：**"agentic commerce 就是往这个生态里加的燃料。"**
