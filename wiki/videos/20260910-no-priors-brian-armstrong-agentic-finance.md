## 概要

三条线：**agentic finance**（给 agent 开账户、x402、微支付的金额分布、专才 agent 市场）、**Coinbase 内部的 AI 工程机制**（按团队/仓库/个人建 "brain"、CEO 自己派 10 个 agent 并行干活）、以及 **New Limit 的表观遗传重编程**（AI 选实验 → 池化筛选 → 动物模型 → 临床）。最后约 5 分钟谈特殊经济区 / freedom cities 作为"监管沙箱"。

## 核心观点

### Agentic finance：不要让 AI 成为 unbanked

- 口号式的立场："**我们不想让 AI 没有银行账户——我们要给 AI 开户，它们也该有金融服务。**"（[00:04:01]）
- 落地的三层（[00:03:01]–[00:05:02]）：
  1. **给人的 AI 顾问**：把过去只有富人能请的投资顾问普及化——讲解组合构建、定投、税务亏损收割、回撤时分批建仓、现金生息，"你可以像跟人说话一样跟它说"。已上线在 Coinbase 产品里。
  2. **给 agent 的账户**：**一条命令粘进你的 agent，它就有了自己的金融账户**，走自托管钱包 + crypto 轨道，因此**没有 KYC 流程**——"我们的 AI agent 没有政府签发的身份证，也不能走进银行网点，至少在它有人形机器人同伴之前不能"。
  3. **两种账户层级都做**（[00:04:01]–[00:05:02]）：既做**与人类身份绑定的、资金隔离的 agentic 子账户**（你只授权这部分给 agent 做交易与支付），也给任意 agent 提供**自托管钱包**——⚠️ 后者"甚至可以融资、可以发币"。
- **他对现状的诊断**（[00:05:02]）：今天 agent 常常**卡在付费墙上**——"这里要填信用卡"、"要开 AWS 资源"、"订酒店要你来填卡号"。未来 agent 应像有自己报销账户的助理或员工；为向后兼容，**大概还需要一张稳定币支撑的信用卡**。
- **协议层**：**x402**（Coinbase 孵化，已捐给 **Linux Foundation**；他说 Google、Cloudflare、AWS 等都在共同推进），并做了 **agentic.market** 展示这个新经济里的支付流量与服务商榜单；商家侧产品是 Coinbase Business（接受稳定币即同时接受人与 agent）（[00:05:02]–[00:06:02]）。

### ⚠️ 本页最具体的一条数据：agentic 交易的金额分布

- 卡组织的最低费用结构是**约 30 美分固定费 + 百分比**，所以"**低于 1 美元基本不成立，低于 30 美分显然荒谬——为了发 1 美分付 30 美分**"（[00:00:00]、[00:06:02]–[00:07:02]）。
- ⚠️ **"我们看到的 agentic commerce 交易里，约 76% 低于 30 美分。"**（[00:07:02]）**本库未核实，且口径为 Coinbase 自己看到的流量。**
- **这些钱买的是什么**（[00:07:02]）：大部分是**取信息**——VC 做研究、要调用付费墙后的数据；招聘者要抓 LinkedIn 数据；**而且很多时候是 agent 向另一个专才 agent 取源数据，形态上几乎就是一次 tool call**。agentic.market 上的头部服务商集中在 search 与金融数据。
- **稳定币支付侧的性能口径**（[00:02:01]–[00:03:01]）：⚠️ "**一秒以内、一美分以内**把钱送到世界任何地方"；并称即使比特币价格下跌，**稳定币支付量仍在持续增长**。

### 专才 agent 市场：小的开放权重模型在窄任务上打赢前沿模型

- 机制（[00:08:02]）：前沿模型被训练成**很好的通才**；而**小的开放权重模型经过微调或 RL，可以在公司内部的专门任务上超过前沿模型**。
- ⚠️ 他给的自家例子：**用 Coinbase 内部 10 万个合规审查案例训练**，一个小的开放权重模型在合规审查队列上**能跑赢前沿模型**（[00:08:02]）。**数字为口述，未核实。**
- 由此推出市场形态：会出现一堆**专才 agent**——"这个 agent 特别擅长给你订披萨"、"那个 agent 是极好的设计师，因为它只在海量私有 Figma 数据上训练过"（[00:08:02]）。
- **宏观推论**（[00:09:03]）：⚠️ "**不太远的将来 agent 会比人多**……那么 agentic 经济在不太远的将来比人类经济更大，也顺理成章。"本库标注：这是信念性推断，不是预测方法。

### 未来还需要钱吗：对 Elon 那条说法的具体反驳

- 他说 Elon 认为**未来不会有钱**；他的理解是"到某个点你开始用能量和质量计量，那才是稀缺资源"，并承认**在极限情形下这有道理**（[00:09:03]–[00:10:03]）。
- 但他的反驳落在**稀缺性的持续时间**（[00:10:03]）：即使机器人与 AI 把商品、食物、住房做得极便宜（价格通缩），**政府印钞可能同时带来通胀压力**；而**土地（尤其可用土地）、能源、芯片**永远还是稀缺的——"**Dyson 球在相当长的未来里都会很贵**"。所以仍然需要交换媒介。
- 他的总结句：⚠️ "**crypto 对人类非常好，而对 AI 将是必需的。**"（[00:10:03]）本库标注为其商业立场。
- Elad 补了一条人员流动的观察（[00:10:03]–[00:11:04]）：早期 AI 社区与 crypto 社区高度重叠，**MIT 这类学校的毕业生按毕业年份分流**——2020 年前后去 crypto，2022 年之后去 AI，"大体是同一批人"。

### ⚠️ Coinbase 内部的"brain"：一套企业侧的自改进机制

这是本期对本库最有增量的一节。Armstrong 明说目标是"**尽可能接近、并真正实现 recursive self-improvement**"（[00:12:04]），但他说的是**工程流程的自改进**，不是模型自改进。

- **结构**（[00:12:04]）：公司有一个 brain，而且**可以分层**——**每个团队一个、每个服务/仓库一个、每个人一个**。
- ⚠️ **一条值得单记的治理设计**：**个人的 brain 在离职时应该可以带走**，他说正在制定相应政策（[00:12:04]）。本库此前没有任何关于"**个人上下文资产的所有权**"的材料。
- **brain 里装什么**（[00:13:04]）：**该服务历史上所有的事故（incident）、必须执行的财务管控、跑过的每一个 A/B 测试、以及完整的 PR 接受/拒绝历史**。⚠️ "**今天它就是 markdown 文件，说到底挺简单。**"团队负责人随时能进去看。
- **闭环的关键一步**（[00:13:04]–[00:14:05]）：agent 改代码时先**吃掉 brain**；人类 review 发现它漏了东西时，**偷懒的做法是手改一下就发**——而他们要强制的是：**把这次纠正的上下文写回 brain**，于是不只修了这一次，而是修了之后所有次。结果是"**一次成功（one-shot）的 PR 接受率随时间持续上升**，你就得到了一个递归自改进的系统"。
- **内部 harness 叫 Toshi**（[00:14:05]）：已接上各类工具，**可以通过 x402 协议直接调用并付费给外部供应商**；也把"改 PR 时顺手编辑 brain"做进了 harness。
- ⚠️ **CEO 自己在发功能（一手记录）**（[00:14:05]–[00:15:07]）：他让一个"高端贵模型"为一个较复杂的功能做计划，**拆成 3 个阶段、每阶段 10 个可并行的件**；然后让它**并行起 10 个 agent 执行第一阶段，并自行推荐用哪个（更便宜的）模型**——结果起了一批开源模型和一批 Grok。"**录这期播客前两分钟，它 ping 我说第一阶段 10 件都做完了，等你 review。**"
- **他对这个体验的描述**（[00:15:07]）：以前有想法或发现 bug 就整天在 Slack 上问团队"这个能做吗"；现在**不是去烦团队，而是直接给他们发一个已经做好的 PR 等 review**——"**这很上瘾。**"
- Elad 的观察（[00:16:07]）：非工程背景的人里，用得最好的那批**几乎把它当电子游戏玩**——不断给自己升级、给自己搭递归循环。

### 公司规模与就业：被消灭的是任务，不是人

- 他对"公司平均规模会大幅变小"这个流行说法**明确不接受**（[00:16:07]–[00:17:07]）：**生产率提升 ≠ 公司变小**；"**任务在被自动化或消灭，人没有被消灭。**"
- 具体预期：像 Coinbase 这样的公司**不会缩到 10 个人**，而是**现有的人能做多得多的事、所有事的节奏都加快**；同时"你确实会看到两个人、五个人的公司做出历史上认为不可能的事"，两者同时为真（[00:17:07]）。
- Elad 的推论（他接话、Armstrong 只应了"Yeah"）：这等于**每个人身上的可扩展性变大**，如果收入增长快于团队增长，**利润率应该随时间上升**（[00:17:07]–[00:18:07]）。⚠️ 本库标注：这条是主持人的推演，不是 Armstrong 的断言。

### Everything exchange 与代币化（非 AI，但与上面的 agent 轨道相连）

- ⚠️ **88% 的收入来自非比特币交易**（他说这是最近财报里披露过、所以能谈的数字）；而股价仍与比特币价格高度相关（[00:18:07]）。
- **代币化股票**（[00:19:08]）：先在美国境外上线，称这是**第一个真正的代币化股票产品**——不是合成物、不是衍生品、不是债务凭证，而是**1:1 由托管中的真实证券支撑的证券本身**；稳定币是代币化的第一个大用例（1:1 对应银行存款或美国国债）。
- 需求侧的论证（[00:19:08]）：⚠️ **全球约 40 亿人没有任何券商或美股投资账户**——"就像 Tether 在美国以外成功是因为很多人想要美元计价账户"。接下来是私募信贷、国债、银行存款，"一切都会被代币化"。
- **预测市场**（[00:21:08]–[00:23:08]）：⚠️ 上线数月内达到**约 1 亿美元收入年化**、**季度环比增长超过 100%**（他说以财报电话会为准、具体数字需再核）。他认为体育只是其中一块，更有社会含义的是**政策预测市场**（"如果实施这项政策，一年、两年、三年后失业率会是多少？"）；还有**没有结算日的"观点市场"**（类比股票也没有结算日，你赌的是未来更好或更差）。

### New Limit：AI 选实验 + 池化筛选的表观遗传重编程

- **起点与方法论**（[00:25:08]–[00:27:09]）：Coinbase 2021 上市后他盘点"我看好哪些大趋势"——空间、AI、聚变、脑机接口都已有好团队，**只有长寿领域他认为缺好团队、且"很多是卖蛇油"**。做法是**连办若干场晚宴**，问在场的 CEO 与科学家同一个问题："**从生物学角度看，什么是最有潜力、而今天资金最不足的方向？**"反复出现的答案是**表观遗传重编程**（山中伸弥实验室的早期结果）——区别是**他们不想改变细胞类型，只想恢复年轻时的功能**。
- 他对"抓住灵感窗口"的描述（[00:27:09]）：有三个月停不下来地读与想，"**这种时刻是会腐烂的（perishable），得趁它消失前做点什么**"——他说 2010–2011 年对比特币就是这种感觉。
- **平台形状**（[00:28:10]–[00:29:11]）：
  1. **AI 先行**：转录因子组合的搜索空间极大，⚠️ 他称他们"**建了表观遗传重编程领域领先的前沿模型**"，**由模型推荐下一批该做的实验**；
  2. 在南旧金山的实验室（**约 50–60 人**）跑**大规模池化筛选**找表型命中——"这是在实验室里搬动原子和液体，不是软件"；
  3. 最好的候选进**功能验证（通常动物模型）**，更贵更慢；
  4. 最好的进**人体试验**。
- **进度**（[00:29:11]）：⚠️ 已在**人源化小鼠模型**中实现**至少一种人类细胞类型**的成功重编程；正在**非人灵长类**上测试；**第一个 I 期临床试验明年启动**；预计未来几年还有 3–10 个候选药物出自该平台。
- **路线图**（[00:31:12]–[00:33:12]）：前三个细胞类型是**肝细胞、血管细胞、免疫（尤其 T）细胞**；第一个 I 期适应症是**酒精性肝病（ALD）**——理由是标准的药物开发逻辑：**先挑未满足需求极高的适应症**（这类患者除肝移植外几乎没有选择，且多数等不到）。
- ⚠️ **市场规模的口述估计**（[00:33:12]）：仅 ALD 一项"可能值 200 亿美元左右"；**皮肤年轻化"大概就是一个万亿美元市场"**。
- **底层论证**（[00:33:12]–[00:34:12]）：**要我们命的大多数疾病都与年龄高度相关**——20 多岁时出现一个癌变细胞或一点肝损伤，身体能自己修复；衰老后这个功能丧失。所以**不逐个打疾病的症状，而是打"元问题"**：把细胞恢复到年轻时的功能。

### ⚠️ 认知增强与胚胎编辑（他自称仍无好 thesis）

- 他说自己在琢磨的"前沿想法"之一是**认知增强**（[00:36:12]–[00:37:13]）：援引发育期营养（如叶酸等）在某些国家确实提高 IQ 的观察，设想**针对成人、儿童或胚胎的疗法，把基线认知"抬平一点"**。他明说**自己还没有好的 thesis，"谁有就告诉我"**，并可能为此办一场晚宴。
- 他把这放进一个竞赛框架（[00:37:13]）：⚠️ "**我们正在一场竞赛里：AI 越来越聪明，人类在某个点上也需要掌控自己的演化、变得更聪明。**"加上脑机接口这条混合路线——"有人会选择融合，有人不会"。
- **胚胎编辑**（[00:38:13]）：他投了一家做胚胎编辑的公司（Preventative）；⚠️ 援引 Pew 的调查说**约 80% 的美国人支持用于疾病预防的胚胎编辑**（数字未核实），并预测**这件事会从"有争议"变成"不做才反常"**，类比不系安全带开车。
- Elad 的反方意见（[00:39:14]）：如果将来有"智力套餐 / 健康套餐"，**会不会把所有人推向同一个套餐、从而削减人类的神经多样性**（"智力的福特 T 型车"）。Armstrong 的回答是**他认为恰好相反**（[00:39:14]–[00:41:16]）：人类偏好本身无限多样（每个家长想要的"优秀"不同），而且**很多可能只是"抬高地板"**（不让孩子得精神分裂或抑郁），孩子还是原来的孩子；极限情形下甚至可能出现"能在水下呼吸的鳃、能飞的翅膀"这种**更极端的多样性**。
- ⚠️ 本库标注：这一节两人都明确知道争议性，且双方都是推测；本库只记录论证结构，不作评价。

### 特殊经济区 / freedom cities：把"监管沙箱"当元问题

- 他的框架（[00:41:16]）：他感兴趣的是**能解锁一整类进步的元问题**，而"世界很多地方拖慢进步的就是过度监管"（他点了欧洲，也说美国自己的版本并不完美）。
- Coinbase **投了洪都拉斯的 Prospera**，"就是为了多了解、看它怎么运行"；他说与当地政府有起伏，但认为**接近解决、他们会成功**（[00:42:17]）。
- **freedom cities 构想**（[00:42:17]–[00:43:18]）：在美国联邦土地上划出 10 或 100 平方英里，**在这块地里不必走常规的 EPA 等繁琐流程**——可以直接建数据中心、建核电站、无限制做无人机配送（不必逐项 FAA 批准）；"**先在安全、受限的范围里做实验，看什么行、什么不行；行的再走正常流程推到全美。**"
- 他给的核心判据（[00:43:18]）：⚠️ "**现在的问题是在很多情况下根本没有沙箱可以去试这个创新，这极其压抑。你没法迭代，就没法作为创业者解决问题。**"
- 他也指出当下的替代解释（[00:42:17]）：这类兴趣**在最近这届 Trump 政府之前更高**，因为去监管环境已经在美国本土创造了机会。
- 一条收尾的框架（[00:44:18]）：**"某种意义上美国因为联邦制和州制度，本身就是 50 个特殊经济区"**——他认为这层竞争是美国领先的原因之一，"只是还可以走得更远"。
