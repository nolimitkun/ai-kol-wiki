# Ali Massa（Kavak）

- **背景**: **Kavak** AI 负责人。此前创办 **Opy Analytics**（约 2013 年，前 transformer 时代的机器学习公司，自称服务过约 14500 家公司，做风险算法、物流、预测、营销）；ChatGPT 时刻之后与 Kavak CEO **Carlos** 一起加入 Kavak 做转型。
- ⚠️ **姓名与前公司名均来自自动字幕，本库未核实拼写。**
- **Kavak 是什么**: 拉美的二手车市场——买车、翻新、卖车并提供融资。为此还自建了金融科技、物流和一套 Carfax，因为"**这些基础设施在拉美根本不存在**"，只能垂直自建。
- **本库收录起点**: 2026-08-10 [a16z](a16z.md) ACC podcast 访谈（37 分钟）

## 他在本库中的位置

⚠️ **这是本库第一个"传统实体企业把自己整个重建成 agent 公司"的一手内部叙述**，而且已跑到 **96% 交互、95% 交易由 agent 完成**的规模。

本库此前关于 AI 落地的材料几乎全部来自**卖方**——[Decagon](decagon-founders.md)、[Netic](melisa-tokmak.md)、[Lassie](lassie-founders.md)、[Retell AI](todd-li.md) 都是把 agent 卖给企业的公司。**他是买方兼自建方**，而且是**非科技行业、拉美市场、有大量物理作业（约 800 名技师）**的公司。

⚠️ **由此产生一条本库应当反复引用的差异**：**卖方的诊断天然指向"我们来帮你做"（集成、FDE、落地服务）；他这个买方的诊断指向"没人能替你做"——难点是你不肯拆掉自己的组织。**

## 核心立场

### 架构：一个客户一个 agent

- **他们问自己的问题**："**如果用 2035 年 Fable 10 或 GPT 10 级别的智能，我们会怎么建 Kavak？**"然后照那个答案重建。
- 客户进来时**生成一个专属 agent，带自己的虚拟机**，记得该客户多年交互，**自己定策略、设定最大化其终身价值的长期目标**。
- ⚠️ **他明确与业界主流对立**："**人们还在用专家式的多 agent 系统在建**，而我们醒悟得太晚才发现，**有硬目标的长期运行 agent、而不是工作流**，才能最大化客户满意度。"
- ⚠️ **Opus 4.5 发布后，他们把跑了两年、已带来盈利的系统全部推倒重建**——"智能已经不需要那个图和多 agent 的格架与 harness 了，**因为它会约束这个级别的智能**"。这是本库**第一条"模型进步导致已盈利架构被主动作废"的一手记录**，也是 [swyx"能力过剩会吞掉自建脚手架"](latent-space-hosts.md) 那条判断迄今**成本最高的一个实例**。
- ⚠️ **"self-improving organization"**："人们现在都痴迷于 RSI，这会改进模型。**但过去四千年里，人类的经济价值是由组织交付的，不是由个人交付的。所以你想要自我改进的，是能交付更多经济价值的那个组织。**" ⚠️ 本库标注：这是一句**主张**，不是被验证的机制。

### Evals 是刹车，不是事后补的

- **"我喜欢跑得极快，但要跑得快你得有刹车。**我见过很多公司搞反了：他们**因为没有对的刹车所以试图慢慢来**。我反过来想：**我们能跑多快？取决于我们 evals 的质量。**"
- ⚠️ **一条可直接引用的经验法则**：**花在建 eval 上的工程师时间、token 和钱，与花在建 agent 上大致相同（约 1:1）。**
- **测什么**：**第一位是业务结果——转化了没有。**"**大多数东西就是在这里崩掉的。**"他点名批评测**通话次数、通话分钟数**这类表面 KPI。

### token 的三个层级

⚠️ 本库 [token 经济学](../topics/ai-business-and-value-capture.md) 条线里**第一个由买方提出的分级度量**：

| 层级 | 定义 | 他的评价 |
|---|---|---|
| **Tier 3（最有价值）** | 能算出**每个具体 token 的 ROI** 的 agent | "我现在能做到，因为它们流向的是**在执行组织本职工作**的 agent" |
| **Tier 2** | 只能**间接衡量** | "我看到开发者在代码库里，至少能间接评估" |
| **Tier 1（大多数公司在这）** | 人们只是在用 ChatGPT / 各种 coding 工具 | "**那些 token 后来怎么样了？我完全不知道。**" |

落点：**"这不只是采用率的问题。"** ⚠️ 与 [Elad Gil 的"投出去的 token 的回报率"](no-priors-hosts.md) 是同一诉求的两侧——Elad Gil 从投资人侧指出这个指标缺失，他从买方侧给出了可操作的分级。

### 组织与就业

- ⚠️ **Jedi Academy**：公司内部培训项目，**从 CEO 到 AI 工程师到技师全员参加**，由他本人设计并不断更新（"你没法把这些人送去斯坦福学，因为这是新东西"）。产出标准很硬：**六周后向生产环境发布 AI agent**。
- ⚠️ **他给员工的话，本库照录**："各位，**没有回头路**……**你可以选择去训练、去获得在这个新现实里胜任的技能，也可以选择离开 Kavak，如果这不适合你——但我们就是要往这走。**"
- ⚠️ **"为 agent 工作"是本库 [AI 与就业](../topics/ai-and-jobs.md) 的一个新象限：岗位没变，指挥链变了。**
  - 他先否定主流的 human-in-the-loop：agent 撞墙就丢给二线支持然后忘掉——"**这不管用，因为你没有闭合回路，就没有产生能训练 agent 的数据**"。
  - 他们的做法：**agent 调用一个 API 说"我需要帮助"，而另一边不是 agent 也不是软件，是一个人在帮它。**
  - **"如果你把这个画成组织架构图，那就是一支支人类团队，头上有一个 agent。"**
- **还在招人的岗位在物理世界**：墨西哥约 **800 名技师**，"有大量的灵巧性和感官，极难替代"。给他们配的是同一套 harness 下的助手（Ratatouille 式的"耳边搭档"）。

### 为什么机会在新公司

- **熊彼特的创造性破坏**：创新冲击经济的方式**不是**在位公司采用新技术，而是**在位公司维持原样、被新公司摧毁**。
- ⚠️ **电力/福特的类比（本库最好用的一个历史锚）**：福特流水线所需的技术在 **1879 和 1881 年**就齐了，**工厂本可以早 40 年建成**。但当时的人只是**把煤机换成电机**、保留四层楼加传动轴与皮带的老厂房——"**是的，那能带来收益，但只有 6% 的效率。**"要拿到那个**支撑了美国整个 20 世纪的 3 倍生产率提升**，必须**把工厂拆掉、在平地上重建**。
  - 落点："**计算机时又发生了一次。今天又在发生。人们想采用它，但不愿意重新设计整个公司**……最后给你的是 6% 或 10%，**不是 10 倍**。这是**产业规模上的创新者窘境**。"

## 关键数字（均为自报，本库未核实）

- **96% 的客户交互、95% 的交易完全由 agent 处理。**
- **每天实例化 10 万个 agent**（⚠️ 片头字幕作 10 万–20 万，正文另一处提到"另外 20 万个 agent"，数字前后不一致）。
- **数据库中约 1000 万客户**；激活 1% 即"几亿美元"量级。
- **NPS / 客户满意度提升 3 倍**；agent 转化率起初比人类团队高 **50%**，现为 **2.1 倍**。
- **车贷通常 3 分钟内批准**（对照墨西哥等市场常规的两个月以上）。
- ⚠️ **AI CEO 在墨西哥 Cuernavaca 运行 6 周**：首月目标利润翻倍，**实际 1.5 倍**。⚠️ 样本极小、时间极短，且这是**未达标**的结果，被讲述为成功——本库保留这个落差。
- **技师助手上线后保修下降约 20–26%**（⚠️ 原话为含糊区间，照录不收窄）。

## 预测

- **到 2035 年，以当前改进速度，AI 能够胜任 CEO 与领导层的工作。**
- **深度采用 AI 的难度，将使新公司而非在位公司成为这一轮创造性破坏的主要受益者。**
