# Terry Angelos（VGS）

- **背景**: **VGS（Very Good Security）首席战略官兼董事会成员**。此前在 **Visa** 任高管（自述任内由 Visa 投资了 VGS）；**2006 年与 [Alex Rampell](a16z.md#alex-rampella16z-普通合伙人前-trialpay-创始人) 共同创办 TrialPay**，该公司后被 Visa 收购。
- **出现于**: [a16z 频道](a16z.md)（Alex Rampell 主持）
- **公司在做什么**: **独立的支付凭证金库（vault）**——替商户捕获、保管、更新信用卡凭证并向卡组织换取 **network token**，使商户可以把 **PCI 合规移出范围**、并同时对接多家支付处理商。
- **在本库中的位置**: ⚠️ **本库第一份来自支付基础设施一侧的 agentic commerce 材料**。此前这条线上只有 [Coinbase 的稳定币 / x402 路线](brian-armstrong.md) 与 [DoorDash 的商家侧视角](doordash-founders.md)，**没有人从卡组织轨道内部解释 agent 怎么付钱**。

> ⚠️⚠️ **引用他时必须一并标注的利益相关，是本库收录过的最重的一类**：**主持人 Alex Rampell 自述主导了 a16z 对 VGS 的投资、并与他同为 VGS 董事**；**他本人是 VGS 高管**；**两人还是 20 年前的共同创业伙伴**（[视频页](../videos/20261015-a16z-vgs-agentic-tokens-wallet-wars.md) [00:01:01]–[00:02:01]）。⚠️ **全期是"投资人兼董事访谈自家被投公司高管"，话题就是这家公司的市场位置。本库按业务叙述收录，不按行业分析收录。**

## 核心观点

来源：[a16z / VGS（2026-10-15）](../videos/20261015-a16z-vgs-agentic-tokens-wallet-wars.md)

### ⚠️⚠️ "从观众到演员"：他给 agentic commerce 的分界

> **"过去三个月里，我们经历了一次巨大的跃迁：agent 从我称之为观众的东西，变成了演员。因为它们实际上长出了手脚——而手脚就是支付凭证。"**（[00:00:00]、[00:12:09]）

- ✅ **他给的判据不是模型能力，而是交付物形态**：给儿子找钢琴老师那次，agent **找人、反问、核对日程、订下第一节课**，而不是给一串推荐——**"这比又往我门口扔一个任务要有用无限倍。"**（[00:12:09]–[00:13:09]）
- **由此得到第二个命名：「钱包战争」**——**每个钱包现在都在抢着接到 agent 上**；agent 要的是**已有凭证的消费者数量 + 商户覆盖广度**（[00:13:09]）。

### ⚠️ "Stripe 是 agentic commerce 的 AOL"，以及那把吊灯

（[00:19:12]–[00:25:14]）⚠️ **他明确说 AOL 这个类比是褒义**：**他们想出了让 agentic commerce"就是能用"的办法，代价是围墙花园。**

**他自己的失败案例（本库 agentic commerce 材料里第一份带失败细节的实地记录）**：agent 在 Walmart 找到了他要的户外灯，**但 Stripe Link 没有 Walmart 连接**，于是 **Stripe 签发一张 Visa 一次性虚拟卡代他买下，再作为第二笔交易向他收款**。✅ **东西到了、金额对了**，但埋了两处制度断裂：

1. ⚠️⚠️ **退单找不到商户**：银行账单上只有 Stripe，没有 Walmart。**他讲的那个测试期案例是全期最有说服力的细节——有人为此致电 Amex，Amex 给的联系电话直接打到了一位 Stripe 工程师的手机上**，因为 Stripe 的架构本就不是为处理退单而设的。
2. ⚠️ **商户拿不回客户关系**：Walmart 事后邀他订 Walmart Plus 并抵扣配送费，**交易失败，因为卡是一次性卡**。他给的是规范层解读——**"Walmart 花了很多钱才把我变成客户，他们就有权利向上销售、交叉销售。"** ✅ **本库认为这条比第一条更值得注意：它说明 agent 代付切断的是商户侧的获客经济学，而商户配不配合 agent 恰恰取决于这笔账。**

### agentic token：卡组织轨道给出的答案

（[00:23:14]–[00:26:16]、[00:32:20]–[00:33:20]）

- **机制**：钱包把凭证安全交给 agent、agent 再交给商户，**而被扣款的仍是消费者本人那张卡**。要素是 **agent 必须先在 Visa / MasterCard / Amex 注册**，**交易前声明上下文与额度**（"我是经过验证的 agent，我花不超过 100 美元"），**token 本身"不过是一个新的 16 位数字"**。
- ✅ **它针对的正是上面那两处断裂**：保住退单规则，也保住后续交易。
- ⚠️ **采用量自述（未核实）**：**"三个月前这是零，它根本不存在……现在我们每周做几百万枚"**，并称 VGS 是**"目前为止最大的 agentic token provisioner"**。⚠️ **这是全期利益相关最集中的一句，增速叙事与他的业务位置完全重合。**
- **他的概括**：**"金库正在从单人游戏变成多人游戏，而这让它们值钱得多。"** ⚠️ **他举的例子之一是前沿实验室——原本保管卡只为收订阅费（单人），现在 agent 要用同一张凭证付款（多人）。**

### ⚠️⚠️ 三步交易框架里的第三步，他说无解

（[00:29:18]–[00:33:20]，⚠️ **三步由主持人提出，映射到 agent 由两人共同完成**）✅ **本库认为这是本期最可迁移的一条，因为它不依赖 VGS 的市场地位，而且给出了一个明确的"目前无解"。**

| 步骤（旧世界） | agent 时代的状态 |
|---|---|
| ① 卡是不是真的（mod 10 校验 + 向银行核验） | ✅ **"已解决的问题"** |
| ② 对方是不是卡主（核签名、看 ID） | ⚠️ 互联网时代本就难；**agent 注册机制是针对这一步的答案** |
| ③ ⚠️⚠️ **"你神志清醒到可以做这笔交易吗"**（他说这一步"你大概只在拉斯维加斯见得到"——卡真、ID 对，但喝了 15 杯话都说不清，赌场不会让你付） | ⚠️⚠️ **即"agent 有没有产生幻觉"。他明说："这部分我认为我们还没有完全搞清楚。"** |

- **他举的实例**：让 agent 订圣地亚哥的酒店、限价 500 美元。**卡组织能验证"这是你的 agent、这是你的指令"，新标准也要求 agent 给出上下文**——⚠️ **但"我很难知道你有没有把日期订对"。**
- **他的预期**：**"那套争议机制是未解的……而且很可能 agent 得承担一部分责任。"**

### ⚠️ 三类商户：恐惧、贪婪、别无选择

（[00:36:25]–[00:37:28]）

> **"Amazon 那边也许是恐惧，Walmart 那边也许是贪婪，而 SMB 那边也许是别无选择。"**

- **Amazon**：实质是广告生意（**封锁了某个消费侧 agent**）。
- **Walmart**：**目前没有封锁**——"如果你是地球上最大的零售商之一、有最好的最后一公里配送，这对你全是好事"。
- **Shopify 伞下的大量小商家**：这很可能是一条**关键的新渠道**。

### ⚠️ 开放银行作为前例，以及"有观点的 API"

（[00:37:28]–[00:39:29]）他把核心问题提成权利问题：**"作为 Amazon 的客户，我有没有权利把登录委托给一个 agent？而 Amazon 有没有权利说不？"**

- **他给的前例是 Plaid 与 Chase 的开放银行之争**，而**结局不是任一方全胜，是漫长的谈判式和解**：**"你确实有权拿到这些信息，但只能走我的 API。而我的 API 限制给你多少信息、把账户 token 化，而且我可能会为此收你一笔钱。"**
- ✅ **他给的区分本库认为很准确**：**Chase 那次主要是安全与控制之争；Amazon 这次是"我是一个有观点的 API"**——基于关于你的大量数据，**对你该买什么有意见**，而你的 agent 也有意见。日常类比是 Best Buy 的店员："他的工作是帮你，但他的工作也是拿提成。"
- **落点**：**"最后我认为消费者多半是赢家，但我们不知道那会长成什么样。"**

### 过誉与低估

（[00:40:29]–[00:43:32]）

- ⚠️ **过誉**：**"我不认为我们会迎来 agent 把存款在账户之间搬来搬去追收益、导致储蓄挤兑的局面。"** 理由是摩擦足够多——他明知 Mercury 利率更好，**但 Chase 的账单支付就是更好用、集成更多、设置都在那儿**。
- **低估**：**大量未被变现的需求**。例子是骑行群里每半年推荐一次轮胎的朋友——**"如果我的 agent 在那个群里，每次推荐我都会买。"** 同时他说 agent 也会替人省钱（取消忘了的订阅）。⚠️ **他的根据是一句无支撑的一般化断言："据我所知，人的欲望和需求是无限的。"本库照录并标明——这恰好是整期商业论证的前提。**

### ⚠️⚠️ "任何带 breakage 模型的东西都会垮"

（[00:45:34]–[00:46:35]）✅ **本库认为这条可以直接迁移到支付以外的行业。**

> **"卡的积分之所以存在，是因为我在餐饮上给你一个很大的头条奖励，但你同时也会把钱花在加油上。如果 agent 居间了我们所有的交易，而我只在拿得到积分的那张卡上刷——整个积分奖励生态就垮了。"**
>
> **"任何带 breakage 模型的东西，都会开始垮掉。"**

（breakage = 商家按"一部分权益不会被兑现"来定价：过期积分、忘记取消的订阅、没人读的条款。）✅ **他的落点是中性的**：**"然后我们就得有新的条款。也许更好，也许更糟，但肯定会不一样。"**

## 他给出的、本库无法核实的事实性断言

> 以下全部为**自述**，且他与公司有直接利益关系，本库照录并标注，不作为证据使用。

- **VGS 保管"约三分之一的电商 GMV"的凭证**；客户含**最大的在线商户、最大的新型银行、以及最大的前沿实验室**（[视频页](../videos/20261015-a16z-vgs-agentic-tokens-wallet-wars.md) [00:00:00]、[00:02:01]）。
- **"我们有大约 100 亿条凭证"**（同上 [00:27:16]）。⚠️ **这是对主持人"是不是美国卡的 80%"一问的回答——他没有确认那个百分比，改口给了绝对数。本库照录这个回避，不把 80% 当作任何人的断言。**
- **agentic token "三个月前是零，现在每周几百万枚"**，VGS 是**"最大的 provisioner"**（同上 [00:25:14]–[00:26:16]）。
- **钱包规模**（同上 [00:13:09]–[00:14:09]）：**Stripe Link** 约 3 亿账户 / 约 100 万商户；**Shop Pay** 消费者量级相近 / 约 170 万商户；**PayPal** 4 亿以上账户（⚠️ 他自注"取决于怎么口径"）/ 约 3000 万商户。
- **年流水 10 亿美元以上的商户平均有 3–5 家支付处理商**；**每年约三分之一的卡换号**（25% 来自四年有效期 + 约 5% 来自并购/欺诈等）（同上 [00:07:03]–[00:08:04]）。
- **发卡行曾为在 Uber、Airbnb 上成为默认卡付出"数千万美元"**（他在 Visa 任内所见，同上 [00:16:09]）。
