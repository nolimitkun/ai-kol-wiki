# Brian Armstrong

Coinbase 联合创始人兼 CEO（2012 创办，2021 上市），此前是 Airbnb 工程师。另为 **New Limit** 联合创始人（表观遗传重编程 / 长寿，他自述只担任投资人与董事会成员），并投资 Prospera（洪都拉斯特殊经济区）与 Preventative（胚胎编辑）。

**本库收录他的理由**：他是本库第一个从**支付与交易所一侧**谈 agent 经济的人——不是"谁付钱给模型"（[OpenRouter × Stripe](../videos/20260925-latent-space-openrouter-stripe-token-economy.md)）也不是"agent 替用户下单"（[DoorDash](../videos/20260723-no-priors-doordash-autonomous-delivery.md)），而是**agent 自己持有账户、付钱给另一个 agent**。他同时给出了一套企业内部的"brain + 纠正写回"工程机制，以及自家实验室的 AI-for-bio 流水线。

## 核心观点（2026-09）

来源：[No Priors：给 AI 开银行账户](../videos/20260910-no-priors-brian-armstrong-agentic-finance.md)

- **"不要让 AI 成为 unbanked"**（[00:04:01]）：一条命令粘进 agent 即开户，走自托管钱包 + crypto 轨道，因此**没有 KYC**——"我们的 agent 没有政府签发的身份证"。两种层级都做：**与人类身份绑定、资金隔离的子账户**，以及给任意 agent 的自托管钱包（⚠️ 后者"甚至可以融资、可以发币"）。
- **卡组织费率结构挡死了 agent 微支付**（[00:06:02]–[00:07:02]）：约 30 美分固定费 + 百分比 ⇒ 低于 1 美元基本不成立。⚠️ 他给的分布：**他们看到的 agentic commerce 交易约 76% 低于 30 美分**，而这些钱主要买**信息**（付费墙后的数据、抓取、以及**向另一个专才 agent 取源数据——形态上就是一次 tool call**）。
- **协议层**：x402（Coinbase 孵化、已捐入 Linux Foundation），配 agentic.market 展示流量与服务商（[00:05:02]）。
- ⚠️ **专才 agent 会打赢通才**（[00:08:02]）：小的开放权重模型经微调 / RL 后在窄任务上超过前沿模型——他的例子是**用内部 10 万个合规案例训练的小模型在合规审查上跑赢前沿模型**（数字未核实）。
- ⚠️ **"agent 会比人多，agentic 经济会比人类经济大"**（[00:09:03]）——本库标注为信念性推断。
- **未来仍然需要钱**（[00:09:03]–[00:10:03]）：他说 Elon 认为未来无钱、计量会回到能量与质量，并承认极限情形下成立；但**土地、能源、芯片的稀缺会持续很久**（"Dyson 球在相当长的未来里都会很贵"），所以仍需交换媒介。其商业立场式的总结：⚠️ "crypto 对人类非常好，对 AI 将是必需的。"
- **被消灭的是任务，不是人**（[00:16:07]–[00:17:07]）：他**明确不接受**"公司平均规模会大幅变小"——Coinbase 不会缩到 10 人，而是现有的人做多得多的事、节奏加快；同时"两人、五人的公司能做历史上认为不可能的事"也为真。
- **元问题偏好**（[00:34:12]、[00:41:16]）：不打单个疾病的症状而打"细胞功能恢复"这个元问题；不逐条争监管而要**特殊经济区作为沙箱**——⚠️ "现在的问题是根本没有沙箱可以试，你没法迭代就没法解决问题。"

## 企业内部的 AI 工程机制（一手记录）

- **brain 的分层**（[00:12:04]）：公司一个、**每个团队一个、每个服务/仓库一个、每个人一个**。⚠️ 一条治理设计：**个人的 brain 在离职时应该可以带走**，他说正在定政策。
- **brain 的内容**（[00:13:04]）：该服务的全部历史事故、必须执行的财务管控、跑过的每个 A/B 测试、完整的 PR 接受/拒绝历史。⚠️ "今天它就是 markdown 文件。"
- **闭环的关键一步**（[00:13:04]–[00:14:05]）：人类 review 发现 agent 漏了东西时，**不能手改了就发，必须把纠正的上下文写回 brain**——于是**一次成功的 PR 接受率随时间上升**，他称之为"递归自改进的系统"。
- **内部 harness 叫 Toshi**（[00:14:05]）：可通过 x402 直接付费调用外部供应商；"改 PR 时顺手编辑 brain"已做进 harness。
- ⚠️ **CEO 自己在发功能**（[00:14:05]–[00:15:07]）：让一个贵模型把功能拆成 3 阶段 × 10 件，**并行起 10 个 agent 并让它自行推荐更便宜的模型**（起了一批开源模型与一批 Grok）；"录播客前两分钟它 ping 我说第一阶段都做完了"。他对此的描述是**"不是去 Slack 上烦团队，而是直接发一个做好的 PR 给他们 review——这很上瘾"**（[00:15:07]）。

## New Limit：AI 选实验的表观遗传重编程

- 立项方法是**连办晚宴问同一个问题**："从生物学角度看，什么最有潜力、而今天资金最不足？"反复出现的答案是表观遗传重编程（山中伸弥实验室的早期结果），但**他们只要恢复年轻时的功能，不改变细胞类型**（[00:26:08]–[00:27:09]）。
- 流水线（[00:28:10]–[00:29:11]）：⚠️ **自称领域领先的前沿模型推荐下一批实验** → 实验室（南旧金山，约 50–60 人）跑**大规模池化筛选** → 功能验证（动物模型） → 人体试验。
- ⚠️ 进度：已在**人源化小鼠**中实现至少一种人类细胞类型的成功重编程，正在**非人灵长类**测试，**I 期明年启动**，未来几年预计 3–10 个候选药（[00:29:11]）。
- 路线：肝细胞 → 血管细胞 → 免疫（T）细胞；首个适应症 **酒精性肝病**（未满足需求极高）；⚠️ 口述市场估计 ALD 约 200 亿美元、皮肤年轻化"大概一个万亿美元市场"（[00:31:12]–[00:33:12]）。
- 论证：**要人命的大多数疾病都与年龄高度相关**，所以打"把细胞恢复到年轻功能"这个元问题，而不是逐个打症状（[00:34:12]）。

## 与他人观点的交叉

- **与 [DoorDash（Andy Fang & Stanley Tang）](doordash-founders.md) 的分工**：DoorDash 那期谈的是 agentic commerce 在**商家与配送侧**的形态；Armstrong 补的是**底下的清结算层**，并给出了交易金额分布（76% < 30 美分）——这解释了为什么卡组织轨道接不住这类流量。
- **与 [OpenRouter（Alex Atallah）](openrouter-atallah-midha.md) 的对照**：OpenRouter 记录的是**token 流量与 agentic fraud**；Armstrong 记录的是**agent 作为付款方**。两者拼起来是 agent 经济的收付两端。
- ⚠️ **"recursive self-improvement" 的用法差异**：他指的是**工程流程/组织的自改进**（brain + 纠正写回 ⇒ PR 接受率上升），与本库 [ai-for-ai-and-auto-research](../topics/ai-for-ai-and-auto-research.md) 里实验室侧的 RSI（模型改进模型）**不是同一件事**。本库在该页单独标注，与 [Kavak 的"把自改进的对象从模型换成组织"](../topics/ai-for-ai-and-auto-research.md) 同类。
- **就业判断与 [DHH](dhh.md) 同向而论据不同**：两人都说"被消灭的是任务/中介环节"，但 DHH 强调**人类带宽是瓶颈、因此中介层被挤压**，Armstrong 强调**现有团队的产出放大、节奏加快**；⚠️ 而 DHH 认为 10x 只在"无人类中介"时出现，与 Armstrong"公司不会变小"的结论存在张力。本库并列记录。
- **AI for bio 的对照**：与 [Zuckerberg / CZI Biohub 的"用 AI 建生物学世界模型"](../videos/20260610-no-priors-zuckerberg-czi-biology.md)、[Xaira 的"因果模型需要因果数据"](xaira-team.md)、[Genesis Molecular AI](genesis-molecular-ai.md) 同属"模型选实验、湿实验室当 verifier"这一类；New Limit 的特点是**适应症路径完全照常规药物开发走**（先打未满足需求极高的小适应症）。
