# Garry Tan

- **背景**: **Y Combinator 总裁兼 CEO**。2003 年斯坦福毕业后进微软 Windows Mobile；随后是 Palantir 早期工程师（⚠️ 但见下文"他自述的两次错过"——他第一次拒绝了 Palantir 的邀约）；Posterous 联合创始人；YC 合伙人；Initialized Capital 联合创始人；2023 年起执掌 YC。也是旧金山本地政治的活跃参与者（Garyslist.org）。
- **出现于**: [a16z 频道](a16z.md)（Anish Acharya 主持）
- **在本库中的位置**: **第一次收录 YC 现任 CEO 的完整长谈**。此前 YC 只作为别人口中的背景机构出现。他的价值在于**同时坐在早期投资与重度个人 agent 使用两个位置上**——既给出定价范式判断（纯席位 SaaS 可能消失），又给出具体操作法（skillify、token maxing）。

## 核心立场与观点

### AI 时代的公司形态

- ⚠️ **"一个 markdown 文件就是一名员工"**——"而且是一名每次都把活干得完美、你要它干多少次就干多少次的员工"（[视频页](../videos/20260812-a16z-garry-tan-founder-psychology.md) [00:24:08]）。这是本库对"skill 文件即组织单元"最直白的表述。
- **skillify 的循环**：做一次难任务 → 变成 **markdown + 代码 + 测试** → 放进 cron job；适用范围是"一切"（销售、市场、客服）。第一次一定很烂且很贵，关键是**能不能很快说"agent，这儿错了，改掉"**，那条修改轨迹会被沉淀成 skill 文件（同上 [00:23:07]–[00:24:08]）。
- **规模上限落在数据治理**：markdown 一多就是 **provenance（来源溯源）**与冲突管理问题——"有两条事实时，有溯源你就能说这条更近、这条赢"——**需要一个 cron job 定期扫过去**（同上 [00:26:08]）。
- ⚠️ **token maxing**：**每年五万到十万美元把 agent 开到满，等于活在 2028 年**。机制解释是**前沿实验室对单请求给的算力受限**，要吃满上下文得走 OpenClaw / Hermes Agent 这类自托管 harness，把单请求推到 80 万–100 万 token（同上 [00:22:07]–[00:23:07]）。

### 创业范式

- ⚠️ **"纯按席位计费的 SaaS，不太清楚 5 到 10 年后还存不存在"**——"作为楔子完全没问题，但如果你 2026 年在做这个，**你最好指望它能跳到某种数据或网络效应的护城河上**"；并说两年前"前瞻 12 个月收入 10–20 倍是铁律"，"现在完全不是那么回事了"（同上 [00:15:06]）。
- **共同创始人这条 YC 铁律正在松动**："vibe coding 和 agentic coding 让任何一个人都能变成 400 个自己"，"**我们正处在一次大转型中间**"。但他仍给出为什么一直坚持共创（引 Derek Sivers：一个人在田里跳舞是疯子，第二个人加入才让它变成派对；"说服不了任何人加入的一人邪教，比邪教还糟"）（同上 [00:14:06]–[00:15:06]）。
- ⚠️ **35–45 岁创始人是一个大趋势**——"把这样一个人乘以 400，你可以跑赢 Mag 7 里任何一整个部门"；点名 [Peter Steinberger](peter-steinberger.md) 是完美例子。⚠️ 他同时说 Patrick Collison 那样的人不会变少，即这是**增量而非替代**（同上 [00:27:10]）。
- **代码不再珍贵 → agency 与品味重要性爆表**，而这两样**不是天生的，是练出来的**（同上 [00:19:06]–[00:20:06]）。

### 组织

- **7±2 是所有组织的物理上限**，"政府尤其没准备好"；"**你加上一个 agent，能在脑子里放下三本《哈利·波特》**"（同上 [00:30:12]–[00:31:12]）。
- **API line 会被抹掉，而不是让你往上爬**：他先复述 Venkatesh Rao 的框架（努力爬到 API line 之上），然后说"**我其实认为 AI 抹掉了这条线**"；证据是被投公司发布了**只给 agent 用、不给人用的 bug 上报端点**，且另一端**实时回话**（同上 [00:37:16]）。
- **丰田生产方式的类比**：在线上干活的人应该被允许改这条线，**因为他掌握最多上下文**——他把这当作"AI 让一线拿回决策权"的历史先例（同上 [00:38:17]）。
- ⚠️ **他对官僚的诊断比主持人温和**：主持人称管理阶层是"从创始人模式起算的一百年弯路"；他说当年那个产品经理并不"想浪费我们的时间"，只是"**一天没有那么多小时，我们是极其有限的人**"。他讲的画面是 22 岁在 Windows Mobile 为一个 P3 bug 跨过高速公路、同事**带着棒球棍**去 Windows 团队——"**微软那样的组织大概做不到，但创业公司可以。而且每家创业公司都必须。**"（同上 [00:34:14]–[00:36:15]）

### ⚠️ "white pill"：慢，而且慢是好事（本库应重点并列的一条）

- 被问"这些问题有多少是智能瓶颈"时，他的回答是"**全是人**"：官僚、中层、七加减二会把一切拖慢——"**社会比你想的慢得多，政府比你想的慢得多，世界上每一家公司都比你想的慢得多**"，所以"**这会花 20 年，而那不是坏事，那其实是好事**"（同上 [00:39:18]–[00:40:18]）。
- 他补了一句在硅谷不讨喜的话：**微软这类公司有结构性护城河，"哪儿也不会去"**，"这跟硅谷大多数人会说的'我要创业取代他们全部'有点相反"。
- ⚠️ **他在同一集里公开修正过自己**："成为 OpenClaw 的皈依者让我非常确信这事会马上发生，**而现在我觉得那完全不对**"（同上 [00:44:20]）。**两个判断是自洽的：能力已到，扩散很慢。**

### 判断的方法论：不要 LARP

- **两次"错过"是他全篇的支点**：2003 年在 web 最被唱衰时离开 web 编程；以及 **Peter Thiel 当面开出等于他微软年薪的 7 万美元支票**叫他加入后来的 Palantir，他回答"谢谢您 Thiel 先生，但我今年可能会升到 60 级"——"**我确实升了。以现在算，那是个 20 亿到 40 亿美元的错误。**"（同上 [00:08:03]）
- **由此提炼的判据**："什么最热、我该做什么"**是错的问题**；对的是"**你对什么感兴趣？你独特地知道什么？**"。两次犯错都归因于"**按地图走，而不是低头看地形**"（同上 [00:04:01]、[00:09:04]）。
- **"不要 LARP"**：内核是真诚，而真诚的实质是**勇气**——"我不同意，因为我相信我的直接经验"（同上 [00:02:00]–[00:03:01]）。
- **"我生命里所有牛的东西都有点像邪教"**——定义是"**始于某种与正统相悖的真理或信念**"；第一性原理的知识只能靠下到实验、或找第一手经历的人拿到（同上 [00:10:05]）。

### 下一台计算机

- 形态"**很明显会是语音**"；他要的那个东西是**知道你的希望、恐惧与欲望并锲而不舍朝那个方向帮你的助理**；路径是 computer use、记忆、说话人分离、摄取（同上 [00:41:19]–[00:42:19]）。
- ⚠️ **时间点预测**：**"我猜明年，2027，会是 harness wars。"** 本质是成本问题——今天前沿模型的纯算力"两三年后大概是 50 或 100 块钱"，那时会有**一场争夺十亿消费者的战争**，"**浏览器大战会重开**"（同上 [00:42:19]）。

## 与本库其它人的关系

- **与 [Peter Steinberger](peter-steinberger.md)**：不仅点名他是"35–45 岁创始人"的完美例子，还说是 Brex 的 Pedro 把自己带进 OpenClaw 的。**这是第一次由 YC CEO 从"这该成为组织默认形态"的角度给个人 agent 背书。**
- **与 [Ali Massa / Kavak](ali-massa.md)**：两人同在 a16z 频道相隔两天出现。Kavak 用**有硬目标的长期 agent**、明确反对流程式多 agent；Garry 的 skillify + cron 是**更保守的一侧**（仍然是流程沉淀）。⚠️ **本库并列不裁决。** 但 Kavak 的"自我改进的组织"与 Garry 的 provenance + cron 扫描应互相引用——后者是前者在数据治理层的具体化。
- **与 [Benedict Evans 的价值上移](a16z.md#benedict-evans独立科技分析师前-a16z-合伙人)**：Garry 的"纯席位 SaaS 可能消失"是同一命题的**定价机制版**，但落点不同——Evans 说价值往上游走，Garry 说**得跳到数据或网络效应护城河上**，即价值仍可能留在应用层。
- ⚠️ **与所有加速论叙事的对立**：他的"20 年 white pill"与 [Ryan Greenblatt 的 RSI 时间表](ryan-greenblatt.md)、Kavak 的"六周做到 1.5 倍"构成 2026-08 这批材料里最值得并列的一组分歧——**双方证据类型不同：一边是能力外推，一边是组织观察。** 与 [刘洺堉](ming-yu-liu.md) 属同一阵营但理由不同（Garry 的瓶颈是组织带宽，刘的瓶颈是知识不可垄断）。
- **与 [Jensen Huang 的"任务 vs 工作"](jensen-huang.md)**：他的"中层应该是 agent"是同一区分的**组织版**——被替代的不是岗位而是协调动作。
