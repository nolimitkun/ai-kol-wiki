# 刘洺堉（Ming-Yu Liu）

- **背景**: NVIDIA **研究副总裁 / Cosmos Lab 副总裁**，世界模型 **Cosmos** 项目负责人。台北长大，台湾交通大学学无线通讯，马里兰大学 CV 博士（导师 Rama Chellappa），第一份工作在三菱电机研究院（MERL），2016 年加入 NVIDIA。**从研究员一路做到 VP，据他自述是英伟达第一个走这条路径的人**（[01:22:50]、[01:23:53]）。
- **代表工作**: CoupledGAN、UNIT（无监督非配对图像翻译）、vid2vid、**GauGAN**（SPADE，被译作"马良神笔"）、Edify 系列、**Cosmos 1/2/2.5/3**。带过的实习生包括 **Tim Brooks**（后做出 Sora）、**余家辉**（现 Meta）、**Jeremy Bernstein**（Muon optimizer 作者）。
- **现汇报关系**: 2026 年初离开 NVIDIA Research，改向 senior VP of software（`Dwight`，英伟达第一位软件工程师；⚠️ 拼写未核实）汇报；此前汇报给 Bill Dally。
- **出现于**: [张小珺《商业访谈录》第 150 期](../videos/20260813-zhang-xiaojun-ming-yu-liu-cosmos-world-model.md)（2026-08-13，本库目前唯一一期）
- **在本库中的位置**: **第一份来自 NVIDIA 研究体系内部的一手长篇叙述**。此前 NVIDIA 只以 [Jensen Huang](jensen-huang.md) 的 CEO 视角和别人口中"卖铲子的一方"出现。他提供的是**中间层视角**——研究者如何在基础设施公司里争取算力、被怎样管理、以及 Cosmos 具体怎么做出来。

## 核心立场与观点

### 关于模型竞赛（本库最该反复引用的两条）

- ⚠️ **不接受"一家公司遥遥领先"的叙事**：**"历史上从来没有这样发生过——一家公司掌握所有的科技，其他公司都没有办法去追上。我不觉得 AI 会是一个例外。"** 机制是**人员流动让 knowhow 自然扩散**，并称一家独大"**本身就不是一个稳定的社会状态**"（[视频页](../videos/20260813-zhang-xiaojun-ming-yu-liu-cosmos-world-model.md) [01:17:45]）。
- ⚠️ **模型能力会收敛，靠模型自己不会是区分**：早期就这么判断，因此坚持模型必须与生态结合。终局用软件类比——"现在能活下来的软件公司都有自己的区分方式，我觉得没有理由模型会是不一样"（同上 [01:13:45]、[03:18:10]）。推论：大公司比生态整合，创业公司走大公司**不能走**的问题（《创新者的窘境》；NVIDIA 自己的门槛是"小于 10 亿的生意没兴趣"，[01:18:45]）。
- **对创业者**：不要跟 OpenAI/Anthropic 做同样的事；要解**他们"不能 justify 去解"**的痛点。正例是 Anthropic——早期被认为落后，但**它是最早相信 Coding 的，在 OpenAI 做分散式投资时做集中式投资**（同上 [01:19:47]）。
- **对当下 Coding Agent 同质化**："同质化竞争是很辛苦的一件事情……**我觉得他们做这件事情可能是被迫的**，因为任何人都不希望自己核心科技被掌握在别人手里。但我不觉得这是他们计划的全部。"（同上 [01:20:47]）
- ⚠️ **不必神话模型公司**："我把它当成中医啊，就是一个 black box……**关键是你要拿它干什么**。"（同上 [03:19:10]）；**不是每家公司都要训模型**——"如果是 commodity，你需要建自己的电厂吗？"（同上 [03:31:31]）

### 关于世界模型与 Cosmos

- **拒绝给世界模型下统一定义**："因为用途不同，所以你 model 这个世界的方式不一样"；四类用途：预测、理解、三维重建、policy 基座。定义之争类比 AGI——"**我觉得这不是很重要的一件事情**"（同上 [01:44:20]–[01:48:22]）。
- **Cosmos = world foundation model**，定位是**基座提供方**，因为"不是每一个想从事 Physical AI 的公司都有足够资源做自己要的世界模型"（同上 [01:48:22]）。
- ⚠️ **action 是 first class citizen**——这是他给出的物理世界模型与数字世界模型的分界：数字侧要么以 language 要么以 video 为 first class citizen，"**我们认为一个好的物理世界的 Foundation model，也要把 Action 当成 first class citizen**"（同上 [02:00:35]）。
- **Cosmos 3 把 reason/predict/transfer/policy 合成一个模型**，两条理由：**这些讯号都描述同一个世界** + **foundation model 纳百川**；触发决策的是 Jensen 的 LV 类比（减少陈列商品数反而销售提升，同上 [01:54:27]–[01:56:29]）。双塔（离散/连续）**首要理由是客户可用性**（切开梯度影响），并预告下一步回到单塔（同上 [02:08:41]）。
- **"更好的数据 / 更好的起始点 / 更好的环境"三个落点**，⚠️ 他自己说**第三个最难且"还没发生"**（同上 [01:38:17]、[03:25:20]）。
- **Physical AI 的 ChatGPT moment 判据**：**人示范一两次，机器人就地学会**；核心问题是**泛化**（同上 [03:23:16]、[03:24:18]）。

### 方法论

- **bitter lesson 的个人版**：2021 年因"GAN 不 scalable"果断带团队转 diffusion——"**不 scalable 的东西最后做不远**"；"你在做选择的时候，要找更加 scalable 的"（同上 [00:55:24]–[00:59:29]）。
- ⚠️ **"其实做大模型没有什么 secret sauce"**——严格实验、控制变数、累积知识；配套比喻是"**deep learning 就很像中医一样，就是试出来的**"（同上 [02:07:41]、[02:16:48]）。
- **迭代速度 > 算法，且明确受 DeepSeek 影响**（"它可以一年内迭代三次"）；排序是"**能用 data 解就用 data 解，不用开发算法**"（同上 [01:51:26]、[03:30:28]）。
- **孙子兵法"备多则力寡"是他反复使用的思维工具**（全篇出现三次）：用来解释 OpenAI 收缩 Sora、解释 Cosmos 合并模型、解释单一任务模型可以放弃什么。
- ⚠️ **重新定义"创新"的标准**："所有的这些大语言模型都是 Transformer 架构，你可以讲大家都没有创新，但是**它的那些细节会让某些模型比另外一些模型好很多**……我越来越不重视这些东西是不是一个革命性的原创。对我来讲，它有用、产生 impact，是它的重点。"（同上 [01:58:33]）

### 关于开源与"low ego"

- **开源动机是生态而非理念**：不只开源模型，还开源训练框架与部分合成数据；⚠️ 明确对照"**Frontier Lab 很多走向闭源，即使写 paper 也不愿讲关键环节。我们决定走不一样的道路**"，并说"**我不担心别人可以做出一模一样的东西**"（同上 [01:58:33]–[01:59:35]）。
- **对同行的喊话**："如果说你用我们做出比我们更好的模型，这模型也是开源的……**所以你就比我们好，我们也觉得这是一件好事**"（同上 [02:42:17]）。面对"英伟达又想卖我卡"的反诘，回答是"对，那你需要做运算嘛"。
- ⚠️ **被直接追问"这真的 low ego 还是一种隐藏"**："**我觉得是一种 confidence，是一种自信**……我对我自己做的东西要求很高，但我的目标并不是击败对手。" 他解释研究员为什么天然 high ego：**论文要被接收就得 state-of-the-art，而 state-of-the-art 代表要击败所有人**。他现在的表述是"**具备做 number one 模型的能力，但是做出对这个世界贡献最大的事情**"（同上 [03:02:50]、[03:11:04]）。

### 关于中美

- **对中国模型**："非常的 impressive"，点名 DeepSeek、千问、豆包、MiniMax、Kimi、MiMo、混元、智谱（同上 [03:14:07]）。
- ⚠️ **一条结构性差异**：**美国 Frontier Lab 现在很少招实习生，knowhow 留在内部；中国这些公司招很多实习生，把 knowhow 传出去。** 他定性为"对人类整个知识扩增……是一件好事"，与他的口号一致——"**研究的茂盛程度应该是根据 idea 多快从一个人的脑袋流到另外一个人脑袋去**"（同上 [03:14:07]、[00:01:11]）。
- **不认可"硅谷已被 LLM 催眠"（谢赛宁语）**：领先公司确实从 LLM 出发，且"我现在已经不知道没有 Coding Agent 我要怎么过下去"；"**你很难想象一个人、就这么聪明的人，一辈子就只做 LLM**"（同上 [03:15:09]）。
- **中美机器人产业**：**美国做本体的只有 Tesla 和 Figure AI**，中国很多家；中国制造业构成"可以做一些在美国不容易做到的事情"的条件（同上 [03:22:13]）。

### 对 [Jensen Huang](jensen-huang.md) 与 NVIDIA 组织的一手观察

- **不裁员 / 无末位淘汰 / 不赛马**：疫情期砍差旅、砍 Slack 而非砍人；⚠️ 他也说出了**代价**——技术换代时员工转型比直接换人慢（同上 [02:50:27]–[02:53:37]）。
- **mission is the boss + top-5 email**：公司像有机体而非固定框架，"**Cosmos 就是这样一个案例**"；⚠️ 他点名苹果可能是资讯透明的反例（同上 [02:59:48]）。
- **Jensen 的决策法则 = first principle + prioritization**，他推想 Jensen 靠每天读大量 email 强迫自己快速判断轻重来练这个能力（同上 [01:28:59]–[01:31:05]）。
- **zero-billion-dollar business / 造市场而非存量竞争**："CUDA 就是造市场"；风险论证是反的——"**你不做这件事情更加 risky**"（同上 [00:28:45]、[03:33:31]–[03:34:31]）。
- ⚠️ **"Cosmos 97"**：做完 Cosmos 1 时 Jensen 说"你就做到 Cosmos 97"，他的解读是 commitment 而非数字（同上 [01:36:15]）。
- ⚠️ **最记得的一句批评**：他说竞品 setting 不公平，Jensen 回"**Are you a quiet baby？这世界上没有什么是公平的。**"——"我后来就不再找理由了"（同上 [03:08:58]）。
- **对 Jensen 的形容**："**我们叫他六边形战士**"——能深到 register 级架构细节，也能教 marketing 与定价（同上 [03:06:55]）。
