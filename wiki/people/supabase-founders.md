## 核心观点

- ⚠️⚠️ **"每一个 Postgres operator 在某些条件下都会丢数据"**——这是从头重写 Multigres（Postgres 版 Vitess）的理由；验证是**1,000 次连续 failover 不丢数据**；而 Vitess 作者 Sugu 加入后把**兼容性而非 sharding 定为第一目标**（[Latent Space 访谈](../videos/20261028-latent-space-supabase-declarative-schema-billions-of-databases.md) [00:09:06]–[00:11:07]）。
- ⚠️⚠️ **声明式 schema 是为 agent 做的**：Postgres 行业标准是 migration 文件的历史日志，**"你让 agent 面对一千个文件、问它这张表是什么形状，它只能猜"**；于是把整个库的形状做成声明式文件（新库 **PG Delta**）。工作假设是**"agent 大体上会在代码上操作，它们必须在文件系统上非常快地迭代"**（[00:58:28]–[01:00:29]）。
- ⚠️⚠️ **企业侧明确放弃迁移、只做 greenfield**：**"你就是没法说服人迁移"**；而对"coding agent 会解放遗留系统"的反驳落在物理层——**"迁移的大部分问题其实不是重写"**，**OLTP 支撑收入应用、停机即损失、双跑即 split brain**；✅ **分界线在 OLTP vs OLAP，不在模型强度**（[00:43:22]–[00:50:24]）。
- ⚠️⚠️ **agent 改了漏斗的形状**：**注册→激活"基本上 100%，因为那一步是 agent 替你做的"**；而**消费者化流量通常会压低激活与付费转化，"但这两个都涨了"**（[00:32:16]–[00:33:16]）。
- ⚠️⚠️ **"前沿模型都把我们列为首选"是时间先后的意外**：**"你得在 LLM 起飞之前就在市场里待了三到四年，并把自己摆成当时那个领先产品的头号竞争者"**；他们自己说**"完全是意外"**，机制是社区内容被模型吃进去（[00:33:16]–[00:35:17]）。
- ⚠️⚠️ **mode collapse 的担忧**（由写了几十年代码的那位提出）：**"模型会让你懒到根本没人去看细节，然后它们全都收敛到同一种造软件的方式"**；而追问比主持人的分层回答更有力——**"但这些高技能的人，还会继续被培养出来吗？"**（[01:01:31]–[01:03:32]）。
- ⚠️ **CPU 短缺被确认，并直接决定融资方选择**：**"是，有短缺"**；引入 CapitalG 的动机明说是**"我们需要 GCP。我们基本上就是需要更多算力。"** 🔗 与 [Anthropic 平台团队](anthropic-platform-leads.md) 相距一天的"CPU 零和"互为印证（[00:26:11]）。
- ⚠️ **rewrite in Rust 是"开源的一次性升级"**，但**"我不认为它会发生，因为人们就是喜欢自己来"**；✅ **"作为公司我们会 100% 支持它。"**（[01:07:36]–[01:10:37]）
- ⚠️ **"skills 作为护栏"的半衰期**：Lovable 的早期差异化是**写好 skills 阻止 agent 对数据库干蠢事**（关 RLS、把图片塞进 Postgres），**"而现在模型本身已经不干那些蠢事了"**（[00:46:22]–[00:47:22]）。
- ⚠️ **用对照组给销售定薪酬**：每周约 1,000 个 product trigger，**不回邮件的对照组月增 25%、接了电话的增 125%**，**按那 100% 的增量发薪酬**（⚠️ 对照组是自选的，[00:42:22]–[00:43:22]）。
- ⚠️ **AI 支出（自述）**：**约 30 万美元/月、450 人**；✅ **而他们自己否掉了这种记账**——**"重点不该是你花了多少钱，而该是你端到端解决了多少个流程，让那里不再需要人在环里"**（[01:10:37]–[01:13:37]）。
- ⚠️ **异步公司是 agent 时代的资产**：**"围绕 Supabase 建一个公司级 harness，基本上就是把已有文档形式化：你把 AI 指向它，问我们的原则是什么"**（[01:13:37]）。
- ⚠️ **使命裁决了 vibe coding 这个赌注**：**"我们的使命是存储世界的数据……在你起步时就在场，确保他们永远不想离开"**；✅ **而明确的对照反例是 NFT 热（也顺势做了 sign in with Ethereum / Solana，但"没投入大量开发时间"）**（[00:30:13]–[00:32:16]）。
